## 接法

动词ます形去ます ＋ きる。按普通动词变化：きります、きった、きって。

## 意思一：做完、用光

动作做到最后，没有剩下。

```ja
ご飯(はん)を 全部(ぜんぶ) 食(た)べ**きりました**。
gohan o zenbu tabe kirimashita
把饭全吃光了。

一冊(いっさつ)の 本(ほん)を 三日(みっか)で 読(よ)み**きった**。
issatsu no hon o mikka de yomi kitta
三天读完了一本书。

牛乳(ぎゅうにゅう)を 使(つか)い**きって**しまった。
gyuunyuu o tsukai kitte shimatta
牛奶用光了。

給料(きゅうりょう)を 全部(ぜんぶ) 使(つか)い**きる** 人(ひと)は 少(すく)ない。
kyuuryou o zenbu tsukai kiru hito wa sukunai
把工资全花光的人很少。
```

## 意思二：彻底、到极限

不是"做完"，而是状态到了尽头。常接 疲れる、呆れる、わかる。

```ja
一日(いちにち) 歩(ある)いて、疲(つか)れ**きった**。
ichinichi aruite, tsukare kitta
走了一天，累透了。

彼(かれ)の 気持(きも)ちは わかり**きっている**。
kare no kimochi wa wakari kitte iru
他的心情我完全明白。

みんな 呆(あき)れ**きって**、誰(だれ)も 何(なに)も 言(い)いませんでした。
minna akire kitte, dare mo nani mo iimasen deshita
大家都无语了，谁也没说话。
```

## きれない：做不完、数不清

きる 的可能形是 きれる，"能做完"；否定 きれない 是"量太多，做不完"。

```ja
こんなに 多(おお)い 料理(りょうり)は 食(た)べ**きれません**。
konna ni ooi ryouri wa tabe kiremasen
这么多菜吃不完。

星(ほし)の 数(かず)は 数(かぞ)え**きれない**。
hoshi no kazu wa kazoe kirenai
星星数不清。

助(たす)けてもらって、感謝(かんしゃ)し**きれません**。
tasukete moratte, kansha shikiremasen
帮了我这么大的忙，感激不尽。
```

## きれない 和 できない

| | 意思 | 例 |
|---|---|---|
| `食(た)べきれない` | 量太多，吃不完 | 多(おお)すぎて 食(た)べきれない |
| `食(た)べられない` | 不能吃（过敏、规定、坏了） | 卵(たまご)が 食べられない |

`食(た)べきれない` 里包含了"能吃，但吃不完"。

## 中国人容易错的地方

- **接ます形，不接て形。** 食(た)べてきる 错。
- **きる 不是"切"。** 食べきる 的汉字写作 食(た)べ切(き)る，意思不是切食物，是吃完。
- **疲れきる 是"累透"，不是"累完"。** 中文要译成程度。
- **きれない 不是"不能做"。** 是"做不完"。
- **きった 有感情色彩。** 疲れきった、呆れきった 这类说法常带"到极限了"的感叹。

## 练一练

1. 这本书太厚了，一天读不完。
2. 把冰箱里的东西全吃光了。
3. 走了二十公里，累透了。（公里 = キロ）

<details><summary>答案</summary>

1. この 本は 厚すぎて、一日では 読みきれません。
2. 冷蔵庫の 物を 全部 食べきりました。
3. 二十キロ 歩いて、疲れきりました。
