## 接法

| 前面是 | 形式 | 例 |
|---|---|---|
| 动词 | 普通形 ＋ っけ | `行(い)くっけ` |
| い形容词 | 普通形 ＋ っけ | `高(たか)いっけ` |
| 名词、な形容词 | だっけ | `何(なん)だっけ` `学生(がくせい)だっけ` |
| 过去 | たっけ | `言(い)ったっけ` |
| 礼貌 | でしたっけ | `明日(あした)でしたっけ` |

## 用法：记忆模糊的确认

以前知道，现在记不清了，向对方确认或者自言自语。

```ja
明日(あした)の 会議(かいぎ)、何時(なんじ)から**だっけ**。
ashita no kaigi, nanji kara dakke
明天的会议，几点来着？

この 前(まえ)の 約束(やくそく)、覚(おぼ)えている**っけ**。
kono mae no yakusoku, oboete iru kke
之前的约定，你记得来着吗？

彼(かれ)の 名前(なまえ)、何(なん)**だっけ**。
kare no namae, nan dakke
他叫什么来着？

昨日(きのう)、雨(あめ) 降(ふ)った**っけ**。
kinou, ame futta kke
昨天雨下了来着吗？
```

自言自语时最自然：

```ja
あれ、鍵(かぎ) どこに 置(お)いた**っけ**。
are, kagi doko ni oita kke
诶，钥匙放哪儿来着。
```

## 礼貌形

对不太熟的人用 でしたっけ、ましたっけ。

```ja
明日(あした)の 集合(しゅうごう)は 十時(じゅうじ)**でしたっけ**。
ashita no shuugou wa juuji deshita kke
明天集合是十点来着吗？
```

## 语气

- 熟人、朋友、同事之间，语气随意。
- 对上级用 でしたっけ，或者更稳的 `〜ましたでしょうか`。
- 只用于"以前知道但忘了"，不是询问全新信息。新信息用普通疑问。

## 中国人容易错的地方

- **名词直接加 っけ 错。** 何っけ 错，是 何だっけ。
- **不是普通疑问。** 新信息问"几点开始"用 何時からですか。
- **语气随意。** 正式场合用 〜でしたっけ / 〜ましたでしょうか。
- **过去是 たっけ。** い形容词过去是 かったっけ。
- **别和 かしら 混。** かしら 是"不知道是不是"，っけ 是"记不清，来着"。

## 练一练

1. 明天的聚会，几点来着？
2. 那个人叫什么名字来着？
3. 这份资料，你交了吗来着？

<details><summary>答案</summary>

1. 明日の パーティー、何時からだっけ。
2. あの 人、何という 名前だっけ。
3. この 資料、出したっけ。

</details>
