## 两种 ています

| 动词类型 | ています 的意思 | 例 |
|---|---|---|
| 持续的动作：吃、看、走 | 正在做 | `食べています` 正在吃 |
| 瞬间完成的变化：住、结婚、知道、穿 | 变化之后的状态 | `住んでいます` 住着 |

第二类动词的动作本身一瞬间就完成了，ています 表示那个结果还在。

## 最常用的状态动词

| 动词 | ています 的意思 |
|---|---|
| `住(す)んでいます` | 住在 |
| `結婚(けっこん)しています` | 已婚 |
| `持(も)っています` | 拥有、带着 |
| `知(し)っています` | 知道 |
| `働(はたら)いています` | 在……工作 |
| `着(き)ています` | 穿着（上衣） |
| `座(すわ)っています` | 坐着 |
| `立(た)っています` | 站着 |
| `疲(つか)れています` | 累了 |

```ja
私(わたし)は 東京(とうきょう)に 住(す)んで**います**。
watashi wa toukyou ni sunde imasu
我住在东京。

姉(あね)は 結婚(けっこん)して**います**。
ane wa kekkon shite imasu
姐姐已婚。

車(くるま)を 持(も)って**います**か。
kuruma o motte imasu ka
你有车吗？

田中(たなか)さんは 赤(あか)い セーターを 着(き)て**います**。
tanaka san wa akai seetaa o kite imasu
田中穿着红毛衣。

父(ちち)は 大学(だいがく)で 教(おし)えて**います**。
chichi wa daigaku de oshiete imasu
父亲在大学教书。
```

## 知っています 和 知りません

"知道"是 `知っています`，"不知道"却是 `知りません`，不说 知っていません。这是日语里最有名的不对称。

```ja
田中(たなか)さんの 電話番号(でんわばんごう)を 知(し)って**います**か。
tanaka san no denwa bangou o shitte imasu ka
你知道田中的电话吗？

はい、知(し)って**います**。
hai, shitte imasu
知道。

いいえ、知(し)り**ません**。
iie, shirimasen
不知道。
```

## 已经去了

`行っています` `来ています` 也是状态：人已经到了那边。

```ja
兄(あに)は 今(いま) 中国(ちゅうごく)へ 行(い)って**います**。
ani wa ima chuugoku e itte imasu
哥哥现在在中国。（去了还没回来）
```

不是"正在去中国的路上"。

## 职业和身份

问职业常用 `何を していますか`，答 `〜で 働いています` 或 `〜を しています`。

```ja
お仕事(しごと)は 何(なに)を して**います**か。
oshigoto wa nani o shite imasu ka
您做什么工作？

貿易(ぼうえき)会社(がいしゃ)で 働(はたら)いて**います**。
boueki gaisha de hataraite imasu
在贸易公司工作。
```

## 中国人容易错的地方

- **"我住在东京"不是 東京に住みます。** 那是"我要住到东京去"。现状用 住んでいます。
- **知っていません 不存在。** 不知道只能说 知りません。
- **結婚しました 和 結婚しています。** 前者是"结了婚"这个事件，后者是"已婚"这个状态。问"你结婚了吗"用后者。
- **持っています 就是"有"。** 东西在身上或名下都用它，比 あります 更像"拥有"。

## 练一练

1. 我住在上海。（上海 = 上海 シャンハイ）
2. 田中有日本的手机。
3. 我不知道那个人。

<details><summary>答案</summary>

1. 私は 上海に 住んでいます。
2. 田中さんは 日本の 携帯を 持っています。
3. あの 人を 知りません。

</details>
