## 接法

て形 ＋ とく，で形 ＋ どく。

| 原形 | 缩约 | 例 |
|---|---|---|
| ておく | とく | `買(か)っとく` |
| でおく | どく | `読(よ)んどく` |
| ておいて | といて | `開(あ)けといて` |
| でおいて | どいて | `読(よ)んどいて` |

## 用法：事先做好、放着

```ja
先(さき)に 買(か)っ**とく**ね。
saki ni kattoku ne
我先买好啊。

資料(しりょう)を 準備(じゅんび)し**ときます**。
shiryou o junbi shi tokimasu
我先把资料准备好。

窓(まど)を 開(あ)け**といて**。
mado o ake toite
把窗户开着。

その まま 置(お)い**といて**ください。
sono mama oi toite kudasai
请就那样放着。
```

## 和 ておく 的关系

意思一样。`とく` 口语，`ておく` 书面或正式。

```ja
先(さき)に 買(か)っておきます。 → 先(さき)に 買(か)っときます。
```

## 中国人容易错的地方

- **不是"解"。** とく 单独是"解开"，这里是 ておく 的缩约。
- **接て形／で形。** 買っとく、置いどく。
- **书面用 ておく。** 作文里别写 とく。
- **男女都用。** 语气随意。
- **和 ておく 意思一样。** 不是新的语法点。
