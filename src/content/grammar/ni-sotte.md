## 接法

名词 ＋ に沿って。更书面用 に沿い，修饰名词用 に沿う／に沿った。

| 形式 | 例 |
|---|---|
| `N に沿って` | `川(かわ)に沿って` 沿着河 |
| `N に沿い` | `方針(ほうしん)に沿い` 按照方针 |
| `N に沿う N` | `計画(けいかく)に沿う 内容(ないよう)` 符合计划的内容 |
| `N に沿った N` | `希望(きぼう)に沿った 案(あん)` 符合希望的方案 |

## 用法一：沿着具体的线

河流、道路、海岸、铁路，物理上的"沿着"。

```ja
川(かわ)に**沿(そ)って**、桜(さくら)が 咲(さ)いています。
kawa ni sotte, sakura ga saite imasu
沿着河边樱花盛开。

この 道(みち)に**沿(そ)って**、店(みせ)が 並(なら)んでいます。
kono michi ni sotte, mise ga narande imasu
沿着这条路排列着店铺。
```

## 用法二：按照方针、计划、希望

抽象方向，后面多是"做、推进、制定"。

```ja
会社(かいしゃ)の 方針(ほうしん)に**沿(そ)って**、新(あたら)しい 事業(じぎょう)を 始(はじ)めます。
kaisha no houshin ni sotte, atarashii jigyou o hajimemasu
按照公司方针开始新业务。

お客(きゃく)さまの ご 希望(きぼう)に**沿(そ)う** 形(かたち)で ご 案内(あんない)します。
okyakusama no go kibou ni sou katachi de go annai shimasu
以符合客人希望的方式为您介绍。

計画(けいかく)に**沿(そ)った** 予算(よさん)を 作(つく)ります。
keikaku ni sotta yosan o tsukurimasu
编制符合计划的预算。
```

## 和 に従って 的区别

| | 语感 | 例 |
|---|---|---|
| `に沿って` | 顺着方向，较柔和 | `計画に沿って` 按计划 |
| `に従って` | 遵从规则、指示，较强 | `規則に従って` 遵守规则 |

计划、方针、希望多用 に沿って；法律、规则、命令多用 に従って。

## 和 に基づいて 的区别

`に基づいて` 是"以……为根据"；`に沿って` 是"顺着……的方向"。`方針に基づいて` 是"根据方针"，`方針に沿って` 是"按照方针推进"。

## 中国人容易错的地方

- **助词是 に。** を沿って 错。
- **に沿う、に沿った 后面接名词。** に沿って 后面接句子。
- **规则用 に従って 更自然。** に沿って 偏"方向"。
- **不是只能表示物理"沿着"。** 抽象用法很多。
- **书面语。** 日常说 〜どおりに、〜に合わせて。

2. 按照顾客的希望安排了座位。
