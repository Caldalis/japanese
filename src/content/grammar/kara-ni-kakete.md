## 接法

A から B にかけて，A 和 B 是时间或地点，后面是在这个范围里发生的事。

## 时间

```ja
今夜(こんや)**から** 明日(あした)の 朝(あさ)**にかけて**、大雨(おおあめ)に なるでしょう。
kon'ya kara ashita no asa ni kakete, ooame ni naru deshou
从今晚到明早会下大雨。

三月(さんがつ)**から** 四月(しがつ)**にかけて**、桜(さくら)が 咲(さ)きます。
sangatsu kara shigatsu ni kakete, sakura ga sakimasu
三月到四月樱花开。

夕方(ゆうがた)**から** 夜(よる)**にかけて** 道(みち)が 混(こ)みます。
yuugata kara yoru ni kakete michi ga komimasu
傍晚到夜里路上堵。

十九世紀(じゅうきゅうせいき)の 終(お)わり**から** 二十世紀(にじっせいき)の 初(はじ)め**にかけて**、この 町(まち)は 大(おお)きく 変(か)わりました。
juukyuu seiki no owari kara nijisseiki no hajime ni kakete, kono machi wa ookiku kawarimashita
从十九世纪末到二十世纪初，这个镇变化很大。
```

## 地点

```ja
九州(きゅうしゅう)**から** 関東(かんとう)**にかけて**、強(つよ)い 風(かぜ)が 吹(ふ)いています。
kyuushuu kara kantou ni kakete, tsuyoi kaze ga fuite imasu
从九州到关东，刮着大风。

駅(えき)**から** 大学(だいがく)**にかけて**、桜(さくら)の 木(き)が 並(なら)んでいます。
eki kara daigaku ni kakete, sakura no ki ga narande imasu
从车站到大学一路都是樱花树。
```

## 和 から〜まで 的区别

| | 边界 | 后面能接什么 |
|---|---|---|
| `A から B まで` | 清楚 | 什么都行，包括长度、次数、时长 |
| `A から B にかけて` | 模糊，大概这一段 | 范围内发生的事，不接精确的量 |

```ja
九時(くじ)**から** 五時(ごじ)**まで** 働(はたら)きます。
kuji kara goji made hatarakimasu
从九点工作到五点。

朝(あさ)**から** 昼(ひる)**にかけて** 雨(あめ)が 降(ふ)りました。
asa kara hiru ni kakete ame ga furimashita
从早上到中午下了雨。
```

第一句有精确的起止，第二句只是"早上到中午这段时间里"。`駅から 学校まで 五百メートル` 不能换成 にかけて，五百米是精确的量。

## 中国人容易错的地方

- **不接精确数量。** `一時から 三時にかけて 二時間 勉強した` 错，用 まで。
- **边界清楚时用 まで。** 营业时间、上班时间都是 から〜まで。
- **前面是时间或地点。** `一年生から 三年生にかけて` 也可以，是把年级当范围。
- **书面偏多。** 天气预报、新闻常用，口语说 `〜から〜まで` 或 `〜ごろから〜ごろまで`。
- **にかけては 是另一个意思。** `料理にかけては 誰にも 負けない` 是"在……方面"，N2 再讲。

## 练一练

1. 从今晚到明天，会下雪。
2. 从关西到关东，气温会上升。（関西、関東、気温が 上がる）
3. 从十一月到十二月，红叶很美。（紅葉が きれい）
4. 判断：「九時から 五時にかけて 働きます」对不对？

<details><summary>答案</summary>

1. 今夜から 明日にかけて、雪が 降るでしょう。
2. 関西から 関東にかけて、気温が 上がるでしょう。
3. 十一月から 十二月にかけて、紅葉が きれいです。
4. 不对。上班时间起止清楚，要说 九時から 五時まで。

</details>
