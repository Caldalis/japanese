## 接法

`間(あいだ)` 是名词，前面按修饰名词的规则接。动词用 ている 形，表示一个持续中的状态。

| 前面是 | 例 |
|---|---|
| 动词 ている | `寝(ね)ている間(あいだ)` |
| 名词 ＋ の | `夏休(なつやす)みの間(あいだ)` `留守(るす)の間(あいだ)` |
| い形容词 | `若(わか)い間(あいだ)` |
| な形容词 ＋ な | `暇(ひま)な間(あいだ)` |

## 間：从头到尾

后面的事和前面的状态一样长，常和 `ずっと`、`〜ていました` 一起用。

```ja
子供(こども)が 寝(ね)ている**間(あいだ)**、ずっと 本(ほん)を 読(よ)んでいました。
kodomo ga nete iru aida, zutto hon o yonde imashita
孩子睡着的那段时间，我一直在看书。

夏休(なつやす)みの**間(あいだ)**、毎日(まいにち) アルバイトを していました。
natsuyasumi no aida, mainichi arubaito o shite imashita
整个暑假每天都在打工。

日本(にほん)に いる**間(あいだ)**、ずっと この 寮(りょう)に 住(す)んでいました。
nihon ni iru aida, zutto kono ryou ni sunde imashita
在日本期间，一直住在这个宿舍。
```

## 間に：其中某一刻

后面的事是瞬间完成的，只占这段时间里的一个点。

```ja
子供(こども)が 寝(ね)ている**間(あいだ)に**、買(か)い物(もの)に 行(い)って きました。
kodomo ga nete iru aida ni, kaimono ni itte kimashita
趁孩子睡着，去买了趟东西。

夏休(なつやす)みの**間(あいだ)に**、一度(いちど) 国(くに)へ 帰(かえ)りました。
natsuyasumi no aida ni, ichido kuni e kaerimashita
暑假期间回了一次国。

留守(るす)の**間(あいだ)に**、泥棒(どろぼう)に 入(はい)られました。
rusu no aida ni, dorobou ni hairaremashita
不在家的时候进了小偷。

昼休(ひるやす)みの**間(あいだ)に** 銀行(ぎんこう)へ 行(い)って きます。
hiruyasumi no aida ni ginkou e itte kimasu
午休时间去趟银行。
```

## 同一句话的两种结尾

```ja
私(わたし)が 出(で)かけている**間(あいだ)**、犬(いぬ)は ずっと 吠(ほ)えていました。
watashi ga dekakete iru aida, inu wa zutto hoete imashita
我出门的那段时间，狗一直在叫。

私(わたし)が 出(で)かけている**間(あいだ)に**、犬(いぬ)が 逃(に)げて しまいました。
watashi ga dekakete iru aida ni, inu ga nigete shimaimashita
我出门的时候，狗跑了。
```

"一直叫"是持续，用 間；"跑了"是一瞬间，用 間に。

| | 后句 | 例 |
|---|---|---|
| `間` | 持续：ずっと 〜ていた | 一直在看书 |
| `間に` | 瞬间：〜た、〜て きた | 去了一趟、来了电话、进了小偷 |

## 和 うちに、ながら 的分工

| | 条件 |
|---|---|
| `間に` | 时间段起止清楚，中性 |
| `うちに` | 状态会结束，要抢在前面，或者不知不觉变化 |
| `ながら` | 同一个人同时做两件事 |

`母が 料理を している間、私は テレビを 見ていた` 两个人各做各的，用 間；换成同一个人就可以用 ながら。

## 中国人容易错的地方

- **加不加 に 看后句。** `寝ている間、電話が 鳴った` 错，电话响是一瞬间，要 間に。
- **动词用 ている。** `寝る間に` 错，`寝ている間に` 对。
- **名词加 の。** `夏休み間に` 少了 の。
- **这里读 あいだ。** `三日間(みっかかん)` 的 間 读 かん，是"三天"的后缀，和本条无关。
- **"之间"的空间意思也是 間。** `駅と 学校の 間に 本屋が ある`，同一个词，地点用法。

## 练一练

1. 妈妈做饭的那段时间，我一直在看电视。
2. 我洗澡的时候来了电话。（お風呂に 入る、電話が ある）
3. 暑假期间去了一次北海道。
4. 不在家的时候，包裹送到了。（留守、荷物が 届く）
