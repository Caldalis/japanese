## 常用疑问词

| 疑问词 | 读音 | 中文 |
|---|---|---|
| `何` | なに / なん | 什么 |
| `誰` | だれ | 谁 |
| `どなた` | | 哪位（礼貌） |
| `どこ` | | 哪里 |
| `いつ` | | 什么时候 |
| `いくら` | | 多少钱 |
| `何時` | なんじ | 几点 |
| `何歳` / `おいくつ` | なんさい | 几岁 |
| `どれ` / `どの` | | 哪个 |
| `どう` | | 怎么样 |
| `どうして` / `なぜ` | | 为什么 |

## 规律：疑问词留在原位

把答案抠掉，填上疑问词，句尾加 `か`，就是问句。和中文完全一样，不像英语要把疑问词挪到句首。

```ja
お名前(なまえ)は 何(なん)ですか。
onamae wa nan desu ka
你叫什么名字？

田中(たなか)です。
tanaka desu
我叫田中。
```

## なん 还是 なに

- 后面是 `で` `と` `の` `です`，或者量词（時、人、歳、円）时，读 **なん**：`何ですか` `何の本` `何時` `何人`。
- 其他情况读 **なに**：`何を 食べますか` `何が ありますか`。
- 单独问"什么？"读 なに。

## 例句

```ja
あの人(ひと)は 誰(だれ)ですか。
ano hito wa dare desu ka
那个人是谁？

会社(かいしゃ)は どこですか。
kaisha wa doko desu ka
公司在哪里？

誕生日(たんじょうび)は いつですか。
tanjoubi wa itsu desu ka
生日是什么时候？

これは いくらですか。
kore wa ikura desu ka
这个多少钱？

今(いま) 何時(なんじ)ですか。
ima nanji desu ka
现在几点？

日本語(にほんご)の 勉強(べんきょう)は どうですか。
nihongo no benkyou wa dou desu ka
日语学得怎么样？
```

## 中国人容易错的地方

- **疑问词后面不加 は。** 疑问词是答案的位置，不能当话题。"谁是老师"是 `誰が 先生ですか`，不是 誰は。
- **问名字、年龄要用礼貌版。** `お名前` `おいくつ` `どなた` 比 名前、何歳、誰 客气得多。
- **回答时省略主语。** `何時ですか` 答 `三時です`，不必说 今は。

## 练一练

1. 那（远处的）是什么？
2. 老师是哪位？（礼貌）
3. 考试是什么时候？（考试 = 試験 しけん）

<details><summary>答案</summary>

1. あれは 何ですか。
2. 先生は どなたですか。
3. 試験は いつですか。

</details>
