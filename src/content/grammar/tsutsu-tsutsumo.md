## つつ：一边……一边

### 接法

动词ます形去ます ＋ つつ，书面语，等于 ながら。

```ja
歩(ある)き**つつ**、考(かんが)えました。
aruki tsutsu, kangaemashita
一边走一边想。

将来(しょうらい)の こと を 思(おも)い**つつ**、毎日(まいにち) 働(はたら)いています。
shourai no koto o omoi tsutsu, mainichi hataraite imasu
一边想着将来的事，一边每天工作。
```

## つつも：虽然……却

### 接法

动词ます形去ます ＋ つつも，表示"明知……却还是……"。

```ja
悪(わる)い と 知(し)り**つつも**、やめられません。
warui to shiri tsutsumo, yameraremasen
虽然知道不好，却停不下来。

体(からだ)に 悪(わる)い と 思(おも)い**つつも**、タバコを 吸(す)ってしまいます。
karada ni warui to omoi tsutsumo, tabako o sutte shimaimasu
虽然觉得对身体不好，还是抽烟。
```

## 和 ながら、ながらも 的区别

| 句型 | 语感 |
|---|---|
| `ながら` | 一边……一边（口语书面都行） |
| `つつ` | 一边……一边（书面） |
| `ながらも` | 虽然……却 |
| `つつも` | 虽然……却（书面） |

## 中国人容易错的地方

- **前接ます形去ます。** 歩くつつ 错。
- **つつ 不是"继续"。** 是"一边……一边"。
- **つつも 是逆接。** 不是"一边……一边"。
- **书面。** 口语用 ながら、けど。
- **和 つつある 不同。** つつある 是"正在逐渐"。

## 练一练

1. 一边看资料一边思考。
2. 虽然知道危险，还是去了。
3. 一边听音乐一边学习。
