## 变形规则

把使役形当二类动词再变被动：させる → させられる。

| 类 | 完整形 | 短缩形 | 例 |
|---|---|---|---|
| 一类 | あ段 ＋ せられる | あ段 ＋ **される** | `書く` → `書かせられる` → `書かされる`；`飲む` → `飲まされる`；`待つ` → `待たされる` |
| 一类 す 结尾 | あ段 ＋ せられる | 无短缩形 | `話す` → `話させられる` |
| 二类 | ＋ させられる | 无短缩形 | `食べる` → `食べさせられる` |
| 三类 | | | `する` → `させられる`，`来る` → `来(こ)させられる` |

一类动词口语几乎都用短缩形，但 す 结尾的不能缩：話さされる 不存在。

## 用法

主语是被迫的人，逼人的人用 `に`。

```ja
子供(こども)の 時(とき)、母(はは)**に** 野菜(やさい)を 食(た)べ**させられました**。
kodomo no toki, haha ni yasai o tabesaseraremashita
小时候被妈妈逼着吃蔬菜。

飲(の)み会(かい)で 先輩(せんぱい)**に** お酒(さけ)を 飲(の)**まされました**。
nomikai de senpai ni osake o nomasaremashita
聚餐时被前辈灌了酒。

一時間(いちじかん)も 待(ま)**たされました**。
ichijikan mo matasaremashita
被晾了整整一个小时。

毎日(まいにち) 残業(ざんぎょう)**させられています**。
mainichi zangyou saserarete imasu
每天被迫加班。

カラオケで 歌(うた)**わされました**。
karaoke de utawasaremashita
在卡拉 OK 被逼着唱了歌。
```

## 三个句型放一起

| 句型 | 谁做 | 感情 | 例 |
|---|---|---|---|
| `〜させる` | 我让别人做 | 上对下 | `弟に 掃除させた` 我让弟弟打扫 |
| `〜させられる` | 别人逼我做 | 不情愿 | `兄に 掃除させられた` 被哥哥逼着打扫 |
| `〜てもらう` | 别人为我做 | 感激 | `兄に 掃除してもらった` 哥哥帮我打扫 |

## 中国人容易错的地方

- **す 结尾的一类没有短缩形。** 話さされる 是错的，要 話させられる。
- **二类不能缩。** 食べさされる 是错的。
- **一定是不情愿。** 愿意做的事不用它。"老师让我发言，我很高兴"要用 発言させてもらった。
- **分清 される 的两个来源。** 飲まされる 是 飲む 的使役被动，される 单独是 する 的被动。
