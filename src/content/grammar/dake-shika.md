## だけ：只，中性

```ja
今日(きょう)は 一人(ひとり)**だけ** 来(き)ました。
kyou wa hitori dake kimashita
今天只来了一个人。

野菜(やさい)**だけ** 食(た)べます。
yasai dake tabemasu
只吃蔬菜。

これ**だけ** ください。
kore dake kudasai
只要这个。
```

## しか〜ない：只，嫌少

后面一定是否定形，意思是"除此之外都没有"，带着不够、遗憾的语气。

```ja
今日(きょう)は 一人(ひとり)**しか** 来(き)**ませんでした**。
kyou wa hitori shika kimasen deshita
今天只来了一个人。（本该更多）

百円(ひゃくえん)**しか** あり**ません**。
hyaku en shika arimasen
只有一百日元。（不够）

日本語(にほんご)**しか** わかり**ません**。
nihongo shika wakarimasen
只懂日语。
```

## 对比

| | 态度 | 谓语 |
|---|---|---|
| `百円だけ あります` | 客观描述，有一百 | 肯定 |
| `百円しか ありません` | 太少，只有一百 | 否定 |

中文都是"只有一百日元"，日语听得出说话人的心情。

## 和其他助词的位置

だけ 和 しか 替换掉 は、が、を；遇到 に、で、へ、と 时放在后面。

```ja
日曜日(にちようび)に**だけ** 休(やす)みます。
nichiyoubi ni dake yasumimasu
只在星期天休息。

田中(たなか)さんと**しか** 話(はな)しません。
tanaka san to shika hanashimasen
只和田中说话。
```

## 中国人容易错的地方

- **しか 后面接了肯定。** 百円しか あります 是错的，必须 ありません。
- **分不清态度。** 被问"有多少钱"客观回答用 だけ，想表达"不够"用 しか。
- **しか 的否定不等于真否定。** 日本語しか わかりません 意思是"懂日语"，不是不懂。
- **だけ 后面的 を 可省。** これだけ ください 比 これだけを ください 自然。

## 练一练

1. 只有一本书。（中性）
2. 只有一本书。（嫌少）
3. 我只在周末看电视。

<details><summary>答案</summary>

1. 本が 一冊だけ あります。
2. 本が 一冊しか ありません。
3. 週末にだけ テレビを 見ます。

</details>
