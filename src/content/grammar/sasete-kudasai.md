## 规则

使役形变て形，加 `ください`。意思是"请让我……"。

```ja
今日(きょう)は 早(はや)く 帰(かえ)**らせてください**。
kyou wa hayaku kaerasete kudasai
今天请让我早点回去。

ちょっと 考(かんが)え**させてください**。
chotto kangaesasete kudasai
让我想一想。

ここは 私(わたし)に 払(はら)**わせてください**。
koko wa watashi ni harawasete kudasai
这顿让我来付。

手伝(てつだ)**わせてください**。
tetsudawasete kudasai
请让我帮忙。

少(すこ)し 休(やす)**ませてください**。
sukoshi yasumasete kudasai
请让我休息一下。
```

## 常用的几句

| 说法 | 场合 |
|---|---|
| `休(やす)ませてください` | 请假 |
| `考(かんが)えさせてください` | 需要时间决定 |
| `払(はら)わせてください` | 抢着付钱 |
| `説明(せつめい)させてください` | 想解释 |
| `自己紹介(じこしょうかい)させてください` | 想自我介绍 |
| `やらせてください` | 想接手做 |

## 更客气

对上司、客户用 `〜させていただけませんか` 或 `〜させていただきたいんですが`。

```ja
来週(らいしゅう) 休(やす)みを 取(と)**らせていただけませんか**。
raishuu yasumi o torasete itadakemasen ka
下周能让我请个假吗？

写真(しゃしん)を 撮(と)**らせていただいても** よろしいでしょうか。
shashin o torasete itadaite mo yoroshii deshou ka
可以让我拍张照吗？
```

## てください 和 させてください

| | 谁做 | 例 |
|---|---|---|
| `〜てください` | 对方做 | `説明してください` 请你说明 |
| `〜させてください` | 自己做 | `説明させてください` 请让我说明 |

## 〜させてもらう：得到允许做了

事后说"承蒙允许，我做了"，谦虚的说法。

```ja
昨日(きのう)は 早(はや)く 帰(かえ)**らせてもらいました**。
kinou wa hayaku kaerasete moraimashita
昨天让我早回了。（感谢）

先生(せんせい)の 本(ほん)を 読(よ)**ませていただきました**。
sensei no hon o yomasete itadakimashita
拜读了老师的书。
```

## 中国人容易错的地方

- **前面是使役形的て形。** 休みさせて、休んでさせて 都错，是 休ませて。
- **"让我"不等于 てください。** 中文"让我看看"说 見せてください（请给我看）和 見させてください（请允许我看）都成立，前者更常用。
- **抢着付钱的固定句。** 払わせてください 比 私が 払います 客气得多。
- **させていただく 别滥用。** 每句都用会显得过度谦卑，请假、拍照、发言这类需要许可的事才用。

## 练一练

1. 请让我来做。
2. 请让我说明一下。
3. 明天能让我请假吗？（客气）

<details><summary>答案</summary>

1. 私に やらせてください。
2. 説明させてください。
3. 明日 休ませていただけませんか。

</details>
