## 接法

普通形 ＋ んだ／のだ。な形容词和名词用 なんだ／なのだ。

| 前面是 | 形式 | 例 |
|---|---|---|
| 动词、い形容词 | 普通形 ＋ んだ | `行くんだ` |
| な形容词 | な ＋ んだ | `静かなんだ` |
| 名词 | な ＋ んだ | `学生なんだ` |

## 用法一：解释背景、原因

```ja
どうした**んですか**。
doushita n desu ka
怎么了？

実(じつ)は、風邪(かぜ)を 引(ひ)いた**んです**。
jitsu wa, kaze o hiita n desu
其实，我感冒了。

明日(あした) 試験(しけん)な**んです**。
ashita shiken na n desu
明天有考试。
```

## 用法二：要求说明

`どうして〜んですか` 是"为什么会这样"，比直接问更柔和。

```ja
どうして 来(こ)なかった**んですか**。
doushite konakatta n desu ka
为什么没来？

何(なに)を して いる**んですか**。
nani o shite iru n desu ka
你在做什么？
```

## 用法三：强调

```ja
私(わたし)が やる**んだ**。
watashi ga yaru n da
我来做。

絶対(ぜったい)に 行(い)く**んだ**。
zettai ni iku n da
一定要去。
```

## んだ 和 のだ 的区别

| | 场合 | 例 |
|---|---|---|
| `んだ` | 口语 | `行くんだ` |
| `のだ` | 书面、文章 | `行くのだ` |

## 中国人容易错的地方

- **な形容词、名词要 なん。** 学生んだ 错，是 学生なんだ。
- **不是"儿子"。** んだ 是语法。
- **语气。** 不是所有句子都能加，多用于解释或强调。
- **书面用 のだ。** 口语才用 んだ。
- **问句 んですか 很常用。** 比 ですか 更柔和。
