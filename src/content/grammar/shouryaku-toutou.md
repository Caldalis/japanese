## 助词省略

`は、が、を` 在口语里经常省掉，`に、で、と` 一般保留。

```ja
ご飯(はん)、食(た)べた？
gohan, tabeta
吃饭了吗？

これ、どこで 買(か)った？
kore, doko de katta
这个，在哪儿买的？

明日(あした)、試験(しけん)？
ashita, shiken
明天考试？
```

## 主语省略

日语本来就不爱说主语，口语更彻底。主语靠上下文和场面补。

```ja
行(い)く？
iku
去吗？（你去吗）

うん、行(い)く。
un, iku
嗯，去。（我去）
```

## 后半省略

话说一半，剩下让对方体会。

```ja
行(い)くけど、一緒(いっしょ)に？
iku kedo, issho ni
我去，一起吗？

ちょっと 忙(いそが)しいんだけど……
chotto isogashii n da kedo
有点忙……（所以不行）
```

## 倒装

把想强调的部分先说出来，剩下的补在后面。

```ja
明日(あした)ね、試験(しけん)なんだ。
ashita ne, shiken nan da
明天啊，有考试。

これ、おいしいよ、すごく。
kore, oishii yo, sugoku
这个好吃，非常。
```

## 其他常见缩约

| 缩约 | 原形 | 例 |
|---|---|---|
| `ちゃう` | てしまう | `食べちゃう` |
| `とく` | ておく | `買っとく` |
| `てる` | ている | `待ってる` |
| `なきゃ` | なければ | `行かなきゃ` |
| `すご` | すごい | `すご うまい` |
| `食べれる` | 食べられる | ら抜き |

`ら抜き言葉` 在口语里很常见，但正式文章仍用 食べられる。

## 中国人容易错的地方

- **省略不等于语法错。** 口语本来就这样。
- **别硬找主语。** 从上下文补。
- **倒装不是病句。** 是为了强调。
- **ら抜き只用于口语。** 作文里别写。
- **听懂语气比听懂每个词重要。**
