## て形能做什么

| 句型 | 意思 | 学在 |
|---|---|---|
| `〜てください` | 请做 | 6.2 |
| `〜ています` | 正在做、处于某状态 | 6.3 6.4 |
| `〜て、〜て` | 先做再做 | 6.5 |
| `〜てから` | 做完之后 | 6.6 |
| `〜てもいいです` | 可以做 | 第 7 单元 |
| `〜てはいけません` | 不可以做 | 第 7 单元 |

先把变形练熟，后面六个句型都是套上去。

## 二类和三类：一步到位

| 类 | 规则 | 例 |
|---|---|---|
| 二类（一段） | 去 る 加 て | `食(た)べる` → `食べて`，`見(み)る` → `見て`，`起(お)きる` → `起きて` |
| 三类 | 固定 | `する` → `して`，`来(く)る` → `来(き)て` |

从 ます形出发：去掉 ます 加 て。食べます → 食べて，します → して，来ます → 来て。

## 一类（五段）：看词典形的最后一个假名

| 词尾 | 变成 | 例 |
|---|---|---|
| う、つ、る | って | `買(か)う` → `買って`，`待(ま)つ` → `待って`，`帰(かえ)る` → `帰って` |
| む、ぶ、ぬ | んで | `飲(の)む` → `飲んで`，`遊(あそ)ぶ` → `遊んで`，`死(し)ぬ` → `死んで` |
| く | いて | `書(か)く` → `書いて`，`聞(き)く` → `聞いて` |
| ぐ | いで | `泳(およ)ぐ` → `泳いで`，`急(いそ)ぐ` → `急いで` |
| す | して | `話(はな)す` → `話して`，`貸(か)す` → `貸して` |

唯一的例外：`行(い)く` → `行って`，不是 行いて。

记忆口诀：う つ る 变 って，む ぶ ぬ 变 んで，く いて ぐ いで，す して。念十遍比看十遍管用。

## 怎么判断是一类还是二类

从 ます形看 ます 前面那个假名：

- え段（え け せ て ね…）→ 二类：食べます、寝ます、開けます。
- い段（い き し ち に…）→ 大多是二类：見ます、起きます、います。但有一批常用词是一类，要单独记：`帰(かえ)ります` `入(はい)ります` `知(し)ります` `走(はし)ります` `切(き)ります` `要(い)ります`。
- 其他段（あ う お）→ 一类：買います、飲みます、話します。

| 动词 | て形 | 动词 | て形 |
|---|---|---|---|
| `行(い)きます` | `行って` | `来(き)ます` | `来(き)て` |
| `帰(かえ)ります` | `帰って` | `食(た)べます` | `食べて` |
| `飲(の)みます` | `飲んで` | `見(み)ます` | `見て` |
| `聞(き)きます` | `聞いて` | `読(よ)みます` | `読んで` |
| `書(か)きます` | `書いて` | `話(はな)します` | `話して` |
| `買(か)います` | `買って` | `します` | `して` |

## 中国人容易错的地方

- **行く 是例外。** 按规则该是 行いて，实际是 行って。这是全表唯一的例外。
- **帰る 入る 知る 是一类。** 它们的て形是 帰って 入って 知って，不是 帰て。
- **一类的 る 和二类的 る。** 乗(の)る 一类 → 乗って；見る 二类 → 見て。分不清就查词性，本站词表里标了Ⅰ Ⅱ Ⅲ。
- **く 和 ぐ 分开。** 書いて 清音，泳いで 浊音，跟着词尾走。
