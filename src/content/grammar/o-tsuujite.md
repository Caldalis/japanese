## 接法

名词 ＋ を 通じて／通して。助词是 を。

| 形式 | 例 |
|---|---|
| `N を通じて` | `インターネットを通じて` 通过网络 |
| `N を通して` | `友人を通して` 通过朋友 |
| `N を通じて`（期间） | `一年を通じて` 一年到头 |

## 用法一：通过媒介、手段、人

信息、经验、联系经过某个中间物。

```ja
インターネットを**通(つう)じて**、世界(せかい)の 情報(じょうほう)が 入(はい)ってきます。
intaanetto o tsuujite, sekai no jouhou ga haitte kimasu
通过网络，世界的信息传进来。

友人(ゆうじん)を**通(とお)して**、彼(かれ)に 連絡(れんらく)しました。
yuujin o tooshite, kare ni renraku shimashita
通过朋友联系了他。

この 仕事(しごと)を**通(つう)じて**、多(おお)くの ことを 学(まな)びました。
kono shigoto o tsuujite, ooku no koto o manabimashita
通过这份工作学到了很多。
```

## 用法二：整个期间

`一年を通じて` 是固定说法，"一年到头、全年"。

```ja
この 地域(ちいき)は 一年(いちねん)を**通(つう)じて** 暖(あたた)かいです。
kono chiiki wa ichinen o tsuujite atatakai desu
这个地区一年到头都很暖和。

一年(いちねん)を**通(とお)して**、努力(どりょく)を 続(つづ)けました。
ichinen o tooshite, doryoku o tsuzukemashita
一整年都坚持努力。
```

## 用法三：物理上的穿过（通して）

`通して` 还能表示"穿过、透过"。

```ja
窓(まど)を**通(とお)して**、風(かぜ)が 入(はい)ってきます。
mado o tooshite, kaze ga haitte kimasu
风从窗户吹进来。

レンズを**通(とお)して** 見(み)ると、小(ちい)さく 見(み)えます。
renzu o tooshite miru to, chiisaku miemasu
透过镜片看，显得很小。
```

## 和 によって 的区别

`によって` 表示手段、原因、主体，比较中性；`を通じて` 强调"经过某个中间环节"，有"经由"的画面。`インターネットによって` 也能说，但 `を通じて` 更像"通过网络这个渠道"。

## 中国人容易错的地方

- **助词是 を。** に通じて 错。
- **不是"通过考试"。** 考试合格是 試験に合格する。
- **通じて 更书面。** 日常说 を通して 也行。
- **一年を通じて 是固定说法。** 不要改成 一年に通じて。
- **通して 有物理"穿过"的意思。** 通じて 一般没有。

## 练一练

1. 通过这次旅行，交到了很多朋友。
2. 通过电视知道了这个消息。
3. 这个国家一年到头都有游客。
