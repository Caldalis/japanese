## 接法

| 词类 | 规则 | 例 |
|---|---|---|
| い形容词 | 去 い ＋ そうです | `おいしい` → `おいしそうです` |
| な形容词 | 直接 ＋ そうです | `元気(げんき)` → `元気そうです` |
| 动词 | ます形去 ます ＋ そうです | `降(ふ)ります` → `降りそうです` |
| 特殊 | | `いい` → `よさそうです`，`ない` → `なさそうです` |

## 形容词：看上去

```ja
この ケーキは おいし**そうです**ね。
kono keeki wa oishisou desu ne
这蛋糕看起来好吃。

田中(たなか)さんは 今日(きょう) 元気(げんき)**そうです**。
tanaka san wa kyou genkisou desu
田中今天看起来挺精神。

その かばん、重(おも)**そうです**ね。持(も)ちましょうか。
sono kaban, omosou desu ne. mochimashou ka
那包看起来挺重，我帮你拿吧？

この 本(ほん)は 難(むずか)し**そうです**。
kono hon wa muzukashisou desu
这本书看起来很难。

この 携帯(けいたい)は よさ**そうです**。
kono keitai wa yosasou desu
这手机看起来不错。
```

## 动词：快要、眼看就

```ja
雨(あめ)が 降(ふ)り**そうです**。
ame ga furisou desu
看样子要下雨。

荷物(にもつ)が 落(お)ち**そうです**よ。
nimotsu ga ochisou desu yo
行李要掉了。

もう 少(すこ)しで 終(お)わり**そうです**。
mou sukoshi de owarisou desu
快做完了。
```

## 否定和修饰名词

| | 形式 |
|---|---|
| 形容词否定 | `おいしくなさそうです` 看起来不好吃 |
| 动词否定 | `降りそうに ありません` 看样子不会下 |
| 修饰名词 | `おいしそうな ケーキ`，`元気そうな 人` |

## 一个限制

そうです 是"看上去像"，所以一眼就能确认的东西不用它：漂亮不说 きれいそう，直接 きれいです；红的不说 赤そう。要用在需要判断的性质上：味道、重量、难度、心情。

## 还有一个 そうです

`雨だそうです` 是"听说会下雨"，前面接简体，名词加 だ。这是传闻，第 25 单元学。记住区别：`降りそうです` 看样子要下，`降るそうです` 听说要下。

## 中国人容易错的地方

- **い形容词必须去 い。** おいしいそうです 意思变成"听说好吃"。
- **いい 是 よさそう。** いそう 不存在。
- **自己的感受不用它。** "我看起来累"没意义，そうです 用于观察别人和东西。
- **动词 そう 是"快要"，不是"看起来在做"。** 田中さんは 寝そうです 是"快睡着了"，不是"看起来在睡"。

## 练一练

1. 这个菜看起来很辣。
2. 那个人看起来很忙。
3. 孩子快哭了。（哭 = 泣きます）

<details><summary>答案</summary>

1. この 料理は 辛そうです。
2. あの 人は 忙しそうです。
3. 子供が 泣きそうです。

</details>
