## 接法

| 原来的助词 | 加 さえ |
|---|---|
| は、が、を | 换成 さえ |
| で（表示主语的"连……也"） | でさえ |
| に、と、から | にさえ、とさえ、からさえ |

## 连……都（肯定）

极端的人或物都能做到，别的更不用说。主语常用 でさえ。

```ja
この 漢字(かんじ)は 小学生(しょうがくせい)**でさえ** 読(よ)めます。
kono kanji wa shougakusei de sae yomemasu
这个汉字连小学生都会读。

先生(せんせい)**でさえ** 間違(まちが)えることが あります。
sensei de sae machigaeru koto ga arimasu
连老师都有出错的时候。

専門家(せんもんか)**でさえ** 答(こた)えられない 問題(もんだい)です。
senmonka de sae kotaerarenai mondai desu
这是连专家都答不上来的问题。
```

## 连……都不（否定）

最基本的事都做不到，别的更做不到。

```ja
忙(いそが)しくて、食事(しょくじ)を する 時間(じかん)**さえ** ありません。
isogashikute, shokuji o suru jikan sae arimasen
忙得连吃饭的时间都没有。

彼(かれ)は 自分(じぶん)の 名前(なまえ)**さえ** 書(か)けません。
kare wa jibun no namae sae kakemasen
他连自己的名字都不会写。

病気(びょうき)で 水(みず)**さえ** 飲(の)めませんでした。
byouki de mizu sae nomemasen deshita
病得连水都喝不下。

あの 人(ひと)は 挨拶(あいさつ)**さえ** しません。
ano hito wa aisatsu sae shimasen
那个人连招呼都不打。

彼女(かのじょ)は 私(わたし)に**さえ** 話(はな)してくれませんでした。
kanojo wa watashi ni sae hanashite kuremasen deshita
她连我都没告诉。
```

## 动词：V ます形去ます ＋ さえ しない

强调"连这个动作都不做"。

```ja
彼(かれ)は 私(わたし)の 顔(かお)を 見(み)**さえ しなかった**。
kare wa watashi no kao o mi sae shinakatta
他连看都没看我一眼。

本(ほん)を 開(ひら)き**さえ しないで**、試験(しけん)を 受(う)けました。
hon o hiraki sae shinaide, shiken o ukemashita
书都没翻开就去考试了。
```

## さえ、も、まで 三个"连"

| | 味道 | 例 |
|---|---|---|
| `も` | 也，轻 | `子供も 知っている` 小孩也知道 |
| `さえ` | 连最极端的都，含"别的更不用说" | `子供でさえ 知っている` 连小孩都知道 |
| `まで` | 甚至连……也加进来了，意外 | `子供まで 知っている` 连小孩也都知道了 |

も 只是"也"，さえ 把这个当成最低标准，まで 是"范围扩大到了这里"。下一条讲 まで。

## 和 さえ〜ば 的区别

| | 形式 | 意思 |
|---|---|---|
| `さえ〜ば` | 后面有 ば | 只要……就 |
| `さえ` | 后面没 ば | 连……都 |

`時間さえ あれば` 只要有时间，`時間さえ ない` 连时间都没有。

## 中国人容易错的地方

- **主语的"连"多用 でさえ。** `先生さえ 間違える` 也通，でさえ 更清楚。
- **さえ 代替 は、が、を。** `名前をさえ` 错。
- **举的例子要够极端。** `大学生でさえ 読める` 不如 `小学生でさえ`，大学生会读不算意外。
- **动词接 ます形去ます ＋ さえ しない。** `見るさえ しない` 错。
- **书面偏多。** 口语里说 `子供でも 知っている`、`名前も 知らない` 更自然。

## 练一练

1. 这道题连老师都不会。
2. 忙得连睡觉的时间都没有。
3. 他连谢谢都不说。（お礼を 言う）
4. 连名字都没问就走了。（名前を 聞く）

<details><summary>答案</summary>

1. この 問題は 先生でさえ わかりません。
2. 忙しくて 寝る 時間さえ ありません。
3. 彼は お礼さえ 言いません。
4. 名前さえ 聞かないで 帰りました。

</details>
