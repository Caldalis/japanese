## 规则

ます形去掉 ます，加 `たい`。たい 之后的变化和い形容词完全一样。

| | 形式 | 例 |
|---|---|---|
| 想 | `〜たいです` | `行きたいです` 想去 |
| 不想 | `〜たくないです` | `行きたくないです` 不想去 |
| 当时想 | `〜たかったです` | `行きたかったです` 当时想去 |
| 当时不想 | `〜たくなかったです` | `行きたくなかったです` 当时不想去 |

```ja
日本(にほん)へ 行(い)き**たいです**。
nihon e ikitai desu
想去日本。

寿司(すし)**が** 食(た)べ**たいです**。
sushi ga tabetai desu
想吃寿司。

今日(きょう)は 何(なに)も し**たくないです**。
kyou wa nani mo shitakunai desu
今天什么都不想做。

子供(こども)の 時(とき)、医者(いしゃ)に なり**たかったです**。
kodomo no toki, isha ni naritakatta desu
小时候想当医生。

新(あたら)しい 携帯(けいたい)**を** 買(か)い**たいです**。
atarashii keitai o kaitai desu
想买新手机。
```

## が 还是 を

たい 句的对象可以用 `が`，强调想要的东西本身；也可以用 `を`，和原来的动词一致。两个都对，初学用 を 不会错。

## 说得客气一点

直接说 たいです 有时显得任性，加 `と思います` 或 `んですが` 会软很多。

```ja
来年(らいねん) 日本(にほん)に 留学(りゅうがく)し**たいと思(おも)います**。
rainen nihon ni ryuugaku shitai to omoimasu
明年想去日本留学。

ちょっと 休(やす)み**たいんですが**。
chotto yasumitai n desu ga
我想稍微休息一下……
```

## 中国人容易错的地方

- **たい 只说自己。** 第三人称"他想去"是 行きたがっています，N4 学。问别人"你想去吗"可以。
- **不要问上司 飲みたいですか。** 问长辈想不想，等于在打探人家的欲望。要说 コーヒーは いかがですか。
- **否定是 たくない。** 不是 たいじゃない，たい 按い形容词变。
- **过去是 たかった。** 中文"当时想"容易漏掉时态。

## 练一练

1. 我想学日语。
2. 今天不想加班。
3. 那时候想买那块表。（那时候 = その時 そのとき）

1. 日本語を 勉強したいです。
2. 今日は 残業したくないです。
