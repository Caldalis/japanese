## 一句话规则

て形的 て 换成 た，で 换成 だ。其他全部不变。

| て形 | た形 |
|---|---|
| `食べて` | `食べた` |
| `行って` | `行った` |
| `飲んで` | `飲んだ` |
| `書いて` | `書いた` |
| `泳いで` | `泳いだ` |
| `話して` | `話した` |
| `して` | `した` |
| `来(き)て` | `来(き)た` |

## 一类动词再过一遍

| 词尾 | て形 | た形 | 例 |
|---|---|---|---|
| う、つ、る | って | った | `買う` → `買った`，`待つ` → `待った`，`帰る` → `帰った` |
| む、ぶ、ぬ | んで | んだ | `飲む` → `飲んだ`，`遊ぶ` → `遊んだ`，`死ぬ` → `死んだ` |
| く | いて | いた | `書く` → `書いた`；例外 `行く` → `行った` |
| ぐ | いで | いだ | `泳ぐ` → `泳いだ` |
| す | して | した | `話す` → `話した` |

## た形能做什么

| 句型 | 意思 | 学在 |
|---|---|---|
| `〜たことがあります` | 曾经做过 | 9.4 |
| `〜たり〜たりします` | 又……又…… | 9.5 |
| `〜たほうがいいです` | 最好做 | 9.6 |
| `〜た後で` | 做之后 | 9.7 |
| 简体句尾 | 口语的"做了" | 第 10 单元 |

た形本身就是简体的过去式。朋友之间说"吃了"是 食べた，"去了"是 行った。

## 中国人容易错的地方

- **て形不熟，た形就不熟。** 两套是一套，回去把第 6 单元的口诀再念一遍。
- **行った 还是例外。** 不是 行いた。
- **飲んだ 的 だ 是浊音。** て形是 で 的，た形就是 だ。
- **た形不是 ました 的简写。** ました 是礼貌体，た 是简体，意思一样，场合不同。

## 练一练

写出た形。

1. 読みます
2. 行きます
3. 来ます
4. 話します
5. 買います

2. 行った

4. 話した
5. 買った
