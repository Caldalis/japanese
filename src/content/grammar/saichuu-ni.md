## 接法

| 前面是 | 例 |
|---|---|
| 动词 ている | `食(た)べている最中(さいちゅう)に` |
| 动作名词 ＋ の | `会議(かいぎ)の最中(さいちゅう)に` `食事(しょくじ)の最中(さいちゅう)に` |

动词只接 ている 形，名词要是"会议、吃饭、比赛、工作"这种表示动作的名词。

```ja
会議(かいぎ)の**最中(さいちゅう)に**、携帯(けいたい)が 鳴(な)って しまいました。
kaigi no saichuu ni, keitai ga natte shimaimashita
开会开到一半，手机响了。

食事(しょくじ)の**最中(さいちゅう)に** 地震(じしん)が ありました。
shokuji no saichuu ni jishin ga arimashita
正吃着饭，地震了。

シャワーを 浴(あ)びている**最中(さいちゅう)に**、停電(ていでん)に なりました。
shawaa o abite iru saichuu ni, teiden ni narimashita
正洗着澡，停电了。

試合(しあい)の**最中(さいちゅう)に** 雨(あめ)が 降(ふ)り出(だ)しました。
shiai no saichuu ni ame ga furidashimashita
比赛进行到一半，下起了雨。

大事(だいじ)な 話(はなし)を している**最中(さいちゅう)に**、邪魔(じゃま)しないでください。
daiji na hanashi o shite iru saichuu ni, jama shinaide kudasai
正在谈要紧事，请别打扰。
```

## 句尾：最中です

"现在正在……中"，用来解释为什么现在不方便。

```ja
今(いま)、その 件(けん)に ついて 調(しら)べている**最中(さいちゅう)です**。
ima, sono ken ni tsuite shirabete iru saichuu desu
那件事现在正在查。

今(いま) 食事(しょくじ)の **最中(さいちゅう)です**ので、後(あと)で かけ直(なお)します。
ima shokuji no saichuu desu node, ato de kakenaoshimasu
现在正在吃饭，稍后回电。
```

## 和 とき、ているところ 的区别

| | 味道 |
|---|---|
| `〜ているとき` | 中性，只说时间 |
| `〜ているところ` | 动作处在"进行中"这个阶段（第 16 单元） |
| `〜ている最中` | 正忙在最要紧的当口，后面多是打断 |

```ja
ご飯(はん)を 食(た)べている**とき**、ニュースを 見(み)ます。
gohan o tabete iru toki, nyuusu o mimasu
吃饭的时候看新闻。

ご飯(はん)を 食(た)べている**最中(さいちゅう)に**、電話(でんわ)が かかって きました。
gohan o tabete iru saichuu ni, denwa ga kakatte kimashita
正吃着饭，电话打来了。
```

第一句是习惯，换成 最中 就怪了，看新闻不是打断。

## 不能用的地方

- 状态动词：`住んでいる最中`、`知っている最中` 错。最中 要一个有头有尾、正在进行的动作。
- 长时间段：`大学の最中に` 错，大学四年不是"当口"，用 `大学の とき` 或 `大学時代(じだい)`。
- 时间名词：`朝の最中`、`夏の最中` 错。名词必须是动作。

## 中国人容易错的地方

- **动词只接 ている。** `食べる最中`、`食べた最中` 都错。
- **后面多是不请自来的事。** 自己计划的事不用 最中：`会議の最中に 発表します` 怪，说 `会議で 発表します`。
- **読音是 さいちゅう。** 同一个汉字读 もなか 是一种和果子，店里看到别念错。
- **"正在"不等于 最中。** 平静地说"我正在吃饭"是 `食べているところです` 或 `食べています`，最中 带着"这会儿正忙"的意思。
- **名词要是动作名词。** `会議、食事、試合、仕事、授業、電話、工事` 这类。

## 练一练

1. 开会开到一半，手机响了。
2. 正吃着饭，客人来了。（お客さん）
3. 现在正在查，请稍等。（調べる）
4. 判断：「夏の最中に 旅行しました」对不对？

<details><summary>答案</summary>

1. 会議の 最中に 携帯が 鳴りました。
2. 食事の 最中に お客さんが 来ました。
3. 今 調べている 最中ですので、少々 お待ちください。
4. 不对。夏 是时间名词，不是动作，要说 夏に 旅行しました 或 夏休みの間に。

</details>
