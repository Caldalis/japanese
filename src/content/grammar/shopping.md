## 问价

`N は いくらですか`。回答数字加 `円(えん)`。四円 `四円(よえん)`、七円 `七円(ななえん)`、九円 `九円(きゅうえん)`，其余规则。

```ja
すみません、これは いくらですか。
sumimasen, kore wa ikura desu ka
请问，这个多少钱？

八百円(はっぴゃくえん)です。
happyaku en desu
八百日元。

この 時計(とけい)は 一万二千円(いちまんにせんえん)です。
kono tokei wa ichiman nisen en desu
这块表一万二千日元。
```

## 要东西

| 说法 | 场合 |
|---|---|
| `N を ください` | 请给我 N，最常用 |
| `N を 数量 ください` | 请给我几个 N |
| `N を お願(ねが)いします` | 更客气，点单、办事 |
| `N に します` | 几个里面选定一个，"我要 N" |
| `N は ありますか` | 有 N 吗 |

```ja
この パンを 二(ふた)つ ください。
kono pan o futatsu kudasai
请给我两个这种面包。

コーヒーを 一(ひと)つ お願(ねが)いします。
koohii o hitotsu onegai shimasu
请来一杯咖啡。

じゃあ、これに します。
jaa, kore ni shimasu
那我要这个。

もっと 大(おお)きいのは ありますか。
motto ookii no wa arimasu ka
有更大一点的吗？

すみません、水(みず)を ください。
sumimasen, mizu o kudasai
不好意思，请给我水。
```

## 付钱

```ja
カードで お願(ねが)いします。
kaado de onegai shimasu
刷卡。

現金(げんきん)で 払(はら)います。
genkin de haraimasu
付现金。

袋(ふくろ)は いりません。
fukuro wa irimasen
不要袋子。
```

支付方式用 `で`，和"坐电车去"的 で 是同一个。

## 店员会说的话

这几句用的是敬语，现在听懂就行，不用会说。

| 店员说 | 意思 |
|---|---|
| `いらっしゃいませ` | 欢迎光临 |
| `〜円(えん)に なります` | 一共……日元 |
| `袋(ふくろ)は ご利用(りよう)ですか` | 要袋子吗 |
| `温(あたた)めますか` | 要加热吗（便利店） |
| `ポイントカードは お持(も)ちですか` | 有积分卡吗 |
| `以上(いじょう)で よろしいですか` | 就这些了吗 |

回答：要 `はい、お願(ねが)いします`，不要 `いいえ、大丈夫(だいじょうぶ)です` 或 `いりません`。

## 中国人容易错的地方

- **数量放在 ください 前面。** パンを 二つ ください，不是 二つの パンを ください。
- **ください 前面要有 を。** 这个 を 口语里常省，初学先带上。
- **四円 读 よえん。** 不是 よんえん。
- **大丈夫です 可以当"不用了"。** 店员问要不要袋子，答 大丈夫です 是婉拒。
- **多少钱问 いくら，不问 何円。** 何円 问的是"几日元"，很少用。
