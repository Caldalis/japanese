## 自己变：なります

| 词类 | 变法 | 例 |
|---|---|---|
| い形容词 | い → く + なります | `寒(さむ)い` → `寒くなります` 变冷 |
| いい | 特殊 | `よくなります` 变好 |
| な形容词 | + に + なります | `元気(げんき)` → `元気になります` 变精神 |
| 名词 | + に + なります | `先生(せんせい)` → `先生になります` 成为老师 |

和上一条 くて・で 的分法一样：い形容词动自己的尾巴，な形容词和名词靠外面加一个字。

```ja
最近(さいきん) 寒(さむ)**くなりました**。
saikin samuku narimashita
最近变冷了。

日本語(にほんご)が 上手(じょうず)**になりました**ね。
nihongo ga jouzu ni narimashita ne
日语变好了呢。

来年(らいねん) 二十歳(はたち)**になります**。
rainen hatachi ni narimasu
明年满二十岁。

息子(むすこ)は 医者(いしゃ)**になりたい**です。
musuko wa isha ni naritai desu
儿子想当医生。
```

## 把它弄成：します

主语主动把东西变成某个状态，对象用 `を`。

| 词类 | 变法 | 例 |
|---|---|---|
| い形容词 | い → く + します | `音(おと)を 小(ちい)さくします` 把声音调小 |
| な形容词 | + に + します | `部屋(へや)を きれいにします` 把房间弄干净 |
| 名词 | + に + します | `コーヒーにします` 我要咖啡 |

```ja
エアコンの 温度(おんど)を 高(たか)**くしました**。
eakon no ondo o takaku shimashita
把空调温度调高了。

もう少(すこ)し 静(しず)か**にして**ください。
mou sukoshi shizuka ni shite kudasai
请再安静一点。

飲(の)み物(もの)は 何(なに)**にしますか**。
nomimono wa nani ni shimasu ka
饮料要什么？

ビール**にします**。
biiru ni shimasu
我要啤酒。
```

`N にします` 在点餐、选东西时就是"我要 N"，用得非常多。

## 中国人容易错的地方

- **い形容词别加 に。** 大きいになります 是错的，要说 大きくなります。
- **なります 没有 を。** 它是自己变，不带宾语：部屋がきれいになります。要说"把房间弄干净"才用 を 加 します。
- **"成为"后面用 に，不用 は 或 が。** 先生になります。
- **变化完成用过去式。** "变冷了"是 寒くなりました，中文的"了"在这里是过去。

## 练一练

1. 天气变暖和了。（天气 = 天気 てんき；暖和 = 暖かい あたたかい）
2. 请把房间弄干净。（干净 = きれい）
3. 我要红茶。（红茶 = 紅茶 こうちゃ）
