## 规则

ない形去掉 い，加 `ければ なりません`。字面是"不做的话不行"，就是"必须做"。

| 动词 | ない形 | 必须 |
|---|---|---|
| `行(い)きます` | `行かない` | `行かなければなりません` |
| `食(た)べます` | `食べない` | `食べなければなりません` |
| `します` | `しない` | `しなければなりません` |
| `来(き)ます` | `来(こ)ない` | `来(こ)なければなりません` |

```ja
明日(あした) 七時(しちじ)に 起(お)き**なければなりません**。
ashita shichiji ni okinakereba narimasen
明天必须七点起床。

今日(きょう)中(じゅう)に レポートを 出(だ)さ**なければなりません**。
kyoujuu ni repooto o dasanakereba narimasen
今天之内必须交报告。

薬(くすり)を 飲(の)ま**なければなりません**。
kusuri o nomanakereba narimasen
必须吃药。

日本(にほん)では 靴(くつ)を 脱(ぬ)が**なければなりません**。
nihon de wa kutsu o nuganakereba narimasen
在日本必须脱鞋。
```

## 三个变体

| 说法 | 场合 |
|---|---|
| `〜なければなりません` | 最正式，规则、义务 |
| `〜なければいけません` | 偏个人的必须，稍口语 |
| `〜ないといけません` | 口语常用 |
| `〜なきゃ` / `〜なくちゃ` | 自言自语、朋友之间：もう 帰らなきゃ |

```ja
もう 帰(かえ)ら**ないといけません**。
mou kaeranai to ikemasen
得回去了。

早(はや)く 寝(ね)**なきゃ**。
hayaku nenakya
得早点睡了。
```

## 问和答

```ja
明日(あした)も 来(こ)**なければなりませんか**。
ashita mo konakereba narimasen ka
明天也必须来吗？

はい、来(き)てください。
hai, kite kudasai
是的，请来。

いいえ、来(こ)**なくてもいいです**。
iie, konakute mo ii desu
不，不来也行。
```

否定回答用 なくてもいいです，见下一条。

## 中国人容易错的地方

- **意思是肯定的。** 看到两个否定不要翻成"不必"。
- **是 なりません，不是 ありません。** 行かなければありません 不存在。
- **不要带 は。** 行かなければは 是错的。
- **"必须"的时态在最后。** 昨天必须做是 しなければなりませんでした。

## 练一练

1. 每天必须学日语。
2. 今天必须加班。（加班 = 残業 ざんぎょう）
3. 得去医院了。（口语）
