## 规则

| 词类 | 变法 | 例 |
|---|---|---|
| い形容词 | い → くて | `安(やす)い` → `安くて` |
| いい | 特殊 | `いい` → `よくて` |
| な形容词 | + で | `静(しず)か` → `静かで` |
| 名词 | + で | `学生(がくせい)` → `学生で` |

前面的词变形，最后一个词照常用 です 结尾。

```ja
この店(みせ)は 安(やす)**くて** おいしいです。
kono mise wa yasukute oishii desu
这家店便宜又好吃。

田中(たなか)さんは 親切(しんせつ)**で** 面白(おもしろ)いです。
tanaka san wa shinsetsu de omoshiroi desu
田中又亲切又有趣。

彼(かれ)は 日本人(にほんじん)**で**、東京(とうきょう)の 学生(がくせい)です。
kare wa nihonjin de, toukyou no gakusei desu
他是日本人，是东京的学生。
```

## 只能连同方向的评价

くて 和 で 表示并列，两个形容词要都是好评或都是差评。一好一坏要用转折的 `が`。

```ja
この 部屋(へや)は 広(ひろ)**くて** 明(あか)るいです。
kono heya wa hirokute akarui desu
这个房间宽敞明亮。

この 部屋(へや)は 広(ひろ)いです**が**、暗(くら)いです。
kono heya wa hiroi desu ga, kurai desu
这个房间宽敞，但是暗。
```

## 否定的连接

否定形 `〜くない` 本身是い形容词，所以照样变：`高くなくて` 不贵而且……。な形容词否定用 `〜ではなくて`。

```ja
この 携帯(けいたい)は 高(たか)**くなくて** 便利(べんり)です。
kono keitai wa takakunakute benri desu
这个手机不贵，而且方便。
```

## 也表示原因

くて 和 で 后面接的如果不是形容词，而是一个结果，就带上"因为"的意思。后半句通常是感受或做不到的事。

```ja
忙(いそが)し**くて**、昼(ひる)ご飯(はん)を 食(た)べませんでした。
isogashikute, hirugohan o tabemasen deshita
太忙了，没吃午饭。

雨(あめ)**で** 試合(しあい)は 中止(ちゅうし)です。
ame de shiai wa chuushi desu
因为下雨，比赛取消了。
```

## 中国人容易错的地方

- **不要用 と 连形容词。** 中文"便宜和好吃"的"和"，日语不能说 安いと おいしい。と 只连名词。
- **い形容词不要加 で。** 安いで 是错的，要去掉 い 换 くて。
- **いい 是 よくて。** いくて 不存在。
- **一好一坏用 が。** 安くて まずい 听起来别扭，要说 安いですが、まずいです。

## 练一练

2. 京都是一座安静而漂亮的城市。
3. 他是中国人，是我的朋友。
