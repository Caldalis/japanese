## 接法

`時(とき)` 是名词，前面按修饰名词的规则接。

| 前面是 | 形式 | 例 |
|---|---|---|
| 动词 | 辞书形 / た形 ＋ とき | `行くとき` `行ったとき` |
| い形容词 | A い ＋ とき | `暇(ひま)じゃないとき` `寒いとき` |
| な形容词 | Na **な** ＋ とき | `暇なとき` |
| 名词 | N **の** ＋ とき | `子供のとき` |

```ja
暇(ひま)**なとき**、何(なに)を しますか。
himana toki, nani o shimasu ka
有空的时候做什么？

子供(こども)**のとき**、よく 川(かわ)で 泳(およ)ぎました。
kodomo no toki, yoku kawa de oyogimashita
小时候常在河里游泳。

寒(さむ)い**とき**は 温(あたた)かい お茶(ちゃ)を 飲(の)みます。
samui toki wa atatakai ocha o nomimasu
冷的时候喝热茶。

わからない**とき**は 聞(き)いてください。
wakaranai toki wa kiite kudasai
不懂的时候请问。
```

## 辞书形还是た形

看 とき 前面那个动作做完了没有。

| | 意思 | 例 |
|---|---|---|
| `V 辞书形 とき` | 做之前、做的过程中 | `日本へ 行くとき、カメラを 買いました` 去日本之前（出发前）买了相机 |
| `V た とき` | 做完之后 | `日本へ 行ったとき、カメラを 買いました` 到了日本之后买了相机 |

主句是过去还是现在不影响这个选择，只看两个动作的先后。

```ja
家(うち)を 出(で)る**とき**、鍵(かぎ)を かけます。
uchi o deru toki, kagi o kakemasu
出门的时候锁门。

家(うち)に 帰(かえ)った**とき**、誰(だれ)も いませんでした。
uchi ni kaetta toki, dare mo imasen deshita
回到家的时候，谁都不在。
```

## 后面的助词

とき 后面可以加 `に`，也可以加 `は` 提示话题，也可以什么都不加。

## 中国人容易错的地方

- **名词别忘 の，な形容词别忘 な。** 子供とき、暇とき 都错。
- **不能接ます形。** 行きますとき 是错的。
- **中文"去日本的时候"是模糊的，日语必须选。** 去之前用 行くとき，到了之后用 行ったとき。
- **時 读 とき。** 三時 的 時 读 じ，一个汉字两个读音。

## 练一练

1. 有空的时候请来玩。
2. 过马路的时候要小心。（过马路 = 道を 渡ります；小心 = 気をつけます）
3. 到了车站的时候给我打电话。

<details><summary>答案</summary>

1. 暇なとき、遊びに 来てください。
2. 道を 渡るとき、気をつけてください。
3. 駅に 着いたとき、電話してください。
