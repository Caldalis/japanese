## 接法

动词辞书形或ない形 ＋ 限り。名词用 の限り。常见固定说法很多。

| 形式 | 意思 | 例 |
|---|---|---|
| `V 辞书形 限り` | 只要 | `生(い)きている限り` 只要活着 |
| `V ない形 限り` | 除非 | `雨(あめ)が 降(ふ)らない限り` 除非下雨 |
| `N の 限り` | 在……范围内 | `力(ちから)の 限(かぎ)り` 竭尽全力 |
| `〜限りでは` | 据……所…… | `見(み)る限りでは` 据看 |

## 用法一：只要……就

前面的状态持续，后面的愿望或状态也持续。正式。

```ja
生(い)きている**限(かぎ)り**、夢(ゆめ)を 持(も)ち続(つづ)けたいです。
ikite iru kagiri, yume o mochitsuzuketai desu
只要活着，就想一直怀抱梦想。

学生(がくせい)である**限(かぎ)り**、割引(わりびき)が 使(つか)えます。
gakusei de aru kagiri, waribiki ga tsukaemasu
只要是学生，就能用折扣。
```

## 用法二：在……范围内、据……所……

`私の知る限り`、`見る限りでは`、`調(しら)べた限りでは` 是固定说法。

```ja
私(わたし)の 知(し)る**限(かぎ)り**、彼(かれ)は 犯人(はんにん)ではありません。
watashi no shiru kagiri, kare wa hannin dewa arimasen
据我所知，他不是犯人。

見(み)る**限(かぎ)りでは**、病気(びょうき)では なさそうです。
miru kagiri dewa, byouki dewa nasasou desu
据我观察，不像生病。

調(しら)べた**限(かぎ)りでは**、事故(じこ)は 起(お)きていません。
shirabete kagiri dewa, jiko wa okite imasen
据调查，没有发生事故。
```

## 用法三：除非……否则

`〜ない限り` 是"除非……，否则……"。

```ja
雨(あめ)が 降(ふ)らない**限(かぎ)り**、試合(しあい)は 行(おこな)われます。
ame ga furanai kagiri, shiai wa okonawaremasu
除非下雨，比赛照常举行。

謝(あやま)らない**限(かぎ)り**、許(ゆる)しません。
ayamaranai kagiri, yurushimasen
除非道歉，否则不原谅。
```

## 其他固定说法

| 说法 | 意思 |
|---|---|
| `〜限りは` | 既然……就 |
| `この限りではない` | 不在此限（告示） |
| `できる限り` | 尽可能 |
| `体力の限り` | 竭尽全力 |

```ja
引(ひ)き受(う)けた**限(かぎ)りは**、最後(さいご)まで やります。
hikiketa kagiri wa, saigo made yarimasu
既然接下了，就做到最后。
```

## 中国人容易错的地方

- **前面是辞书形或ない形。** 生きている限り，不是 生きます限り。
- **私の知る限り 固定用辞书形。** 知っている限り 也可以，但前者更常见。
- **ない限り 是"除非"，不是"只要不"。** 语感是条件。
- **限り 比 うちは 正式。** 口语多用 うちは、間は。
- **限りでは 和 限り 不同。** 一个是"据……所……"，一个是"只要"。

## 练一练

1. 只要我在，就不会让你受苦。
2. 据我所见，他没有说谎。
3. 除非有许可，否则不能进入。

1. 私が いる限り、あなたを 困らせません。
2. 見る限りでは、彼は 嘘を ついていません。
3. 許可が ない限り、入る ことが できません。
