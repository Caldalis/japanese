## 变形规则

| 类 | 规则 | 例 |
|---|---|---|
| 一类 | 词尾 う段 改 お段，加 う | `行(い)く` → `行こう`，`飲(の)む` → `飲もう`，`買(か)う` → `買おう`，`話(はな)す` → `話そう` |
| 二类 | 去 る 加 よう | `食(た)べる` → `食べよう`，`見(み)る` → `見よう` |
| 三类 | 固定 | `する` → `しよう`，`来(く)る` → `来(こ)よう` |

## 用法一：朋友之间的"吧"

ましょう 的简体版。

```ja
もう 遅(おそ)いから、帰(かえ)**ろう**。
mou osoi kara, kaerou
已经晚了，回去吧。

一緒(いっしょ)に 昼(ひる)ご飯(はん)を 食(た)べ**よう**。
issho ni hirugohan o tabeyou
一起吃午饭吧。

そろそろ 行(い)**こうか**。
sorosoro ikou ka
差不多走了吧？
```

`〜(よ)うか` 是 ましょうか 的简体，征求对方意见。

## 用法二：自言自语的决心

```ja
明日(あした)から 早(はや)く 起(お)き**よう**。
ashita kara hayaku okiyou
从明天起早点起吧。

よし、頑張(がんば)**ろう**。
yoshi, ganbarou
好，加油吧。
```

## 中国人容易错的地方

- **一类是 お段 加 う。** 行くう、行きよう 都错，是 行こう。
- **二类别套一类的规则。** 食べろう 是错的，是 食べよう。
- **来よう 读 こよう。** 来る 的所有变形都是 こ 开头：来ない、来よう、来られる。
- **对上司用 ましょう。** 意向形是简体，场合和第 10 单元一样。
