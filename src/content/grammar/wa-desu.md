## 是什么

`N1 は N2 です` 对应中文"N1 是 N2"，但两个成分要分开理解。

- `は` 是话题助词，意思接近"说到 N1……"。写作 は，读作 **wa**，是日语最常见的读音例外。
- `です` 不是"是"，是让句子礼貌结束的词尾。名词句、形容词句都用它收尾。

## 四种形式

| | 形式 | 例 |
|---|---|---|
| 肯定 | N です | `学生です` 是学生 |
| 否定 | N ではありません | `学生ではありません` 不是学生 |
| 过去 | N でした | `学生でした` 以前是学生 |
| 过去否定 | N ではありませんでした | `学生ではありませんでした` 以前不是学生 |

口语里 `ではありません` 常说成 `じゃありません`，意思相同，更随意一点。

## 疑问句：句尾加 か

语序完全不变，只在句尾加 `か`，句末语调上扬。正式书写用句号，不用问号。

```ja
田中(たなか)さんは 先生(せんせい)です**か**。
tanaka san wa sensei desu ka
田中先生是老师吗？

はい、先生(せんせい)です。
hai, sensei desu
是的，是老师。

いいえ、先生(せんせい)ではありません。
iie, sensei dewa arimasen
不，不是老师。
```

## 例句

```ja
私(わたし)は 中国人(ちゅうごくじん)です。
watashi wa chuugokujin desu
我是中国人。

王(おう)さんは 会社員(かいしゃいん)です。
ou san wa kaishain desu
小王是公司职员。

あの人(ひと)は 日本人(にほんじん)ではありません。
ano hito wa nihonjin dewa arimasen
那个人不是日本人。

昨日(きのう)は 休(やす)みでした。
kinou wa yasumi deshita
昨天是休息日。
```

## 中国人容易错的地方

- **把 は 读成 ha。** 只有当助词时读 wa，其他时候仍读 ha，比如 `はい`。
- **到处说 私は。** 日语知道在说谁就省略主语。回答"你是学生吗"直接说 `はい、学生です`。
- **さん 不能用在自己名字后面。** 称呼别人加 `さん`，男女通用，相当于先生、女士、小。说自己只说名字。
- **否定形不要漏 ん。** 是 `ありません`，最后有个 ん。

## 练一练

把下面的句子说成日语，想好再点开答案。

1. 我是学生。
2. 她不是老师。（她 = 彼女 かのじょ）
3. 昨天是星期天。（星期天 = 日曜日 にちようび）

<details><summary>答案</summary>

1. 私は 学生です。
2. 彼女は 先生ではありません。
3. 昨日は 日曜日でした。

</details>
