## 一张表：变化走到哪一步

| 阶段 | 句型 | 例 | 中文 |
|---|---|---|---|
| 刚要开始又停住 | `〜かける` | `泣(な)きかけた` | 差点哭出来 |
| 开始出现 | `〜てくる` | `雨(あめ)が 降(ふ)ってきた` | 下起来了 |
| 缓慢进行中 | `〜つつある` | `変(か)わりつつある` | 正在逐渐改变 |
| 一直到现在 | `〜てきている` | `減(へ)ってきている` | 一直在减少 |
| 完成的结果 | `〜ようになる` | `話(はな)せるようになった` | 会说了 |
| 从现在到将来 | `〜ていく` | `増(ふ)えていく` | 会越来越多 |
| 单向停不下来 | `〜一方だ` | `増(ふ)える一方(いっぽう)だ` | 只增不减 |
| 做到最后 | `〜きる` | `食(た)べきった` | 吃光了 |
| 做到一半 | `〜かける` | `食(た)べかけ` | 吃了一半 |

## ようになる 复习

| 前面是 | 形式 | 例 |
|---|---|---|
| い形容词 | 〜くなる | `寒(さむ)くなる` 变冷 |
| な形容词、名词 | 〜になる | `静(しず)かになる` 变安静 |
| 动词（可能形、辞书形） | 〜ようになる | `話(はな)せるようになる` 变得会说 |
| 动词否定 | 〜なくなる | `飲(の)まなくなる` 不再喝 |

```ja
日本語(にほんご)が 話(はな)せる**ようになりました**。
nihongo ga hanaseru you ni narimashita
日语会说了。

毎朝(まいあさ) 走(はし)る**ように** なりました。
maiasa hashiru you ni narimashita
开始每天早上跑步了。

お酒(さけ)を 飲(の)ま**なくなりました**。
osake o noma naku narimashita
不喝酒了。
```

变化完成用 なりました。还在过程里，用 〜てきました：`話(はな)せるように なってきました` 渐渐能说了。

## 三个"渐渐"

| 说法 | 语感 | 例 |
|---|---|---|
| `だんだん` | 口语，最常用 | `だんだん 暖(あたた)かくなる` |
| `徐々(じょじょ)に` | 稍正式 | `徐々(じょじょ)に 回復(かいふく)する` |
| `次第(しだい)に` | 书面 | `次第(しだい)に 増(ふ)える` |

和 つつある 搭配时，书面词更自然：`徐々(じょじょ)に 変(か)わりつつある`。

## 容易混的三组

### てきた 和 ようになった

```ja
A: 日本語(にほんご)が 話(はな)せるように なりましたね。
B: ええ、毎日(まいにち) 練習(れんしゅう)して、少(すこ)しずつ 話(はな)せるように なってきました。
```
A 看结果：会说了。B 看过程：是慢慢变成这样的。

### つつある 和 ている

`変(か)わりつつある` 是正在变；`変(か)わっている` 是已经变了或变化后的状态。日常动作不能用 つつある。

### 一方だ 和 ばかりだ

`悪(わる)くなる一方(いっぽう)だ` 单向变坏；`遊(あそ)んでばかりだ` 一味地玩。ばかりだ 能接动作，一方だ 只能接变化。

## 中国人容易错的地方

- **变化结果用 ようになる，过程用 てくる。** 中文都译"会了"，日语焦点不同。
- **つつある 只用于书面。** 口语说 てきている。
- **一方だ 前面只能是变化动词。** 遊(あそ)ぶ一方だ 错。
- **きる、かける 接ます形。** 食(た)べきる、食(た)べかける。
- **ていく 是"从现在到将来"，てきた 是"从过去到现在"。** 说话人的位置决定方向。

## 练一练（综合）

1. 最近，这个城市的人口一直在减少。（てきている）
2. 照这样下去，物价只会越来越高。（一方だ）
3. 经济正在慢慢恢复。（つつある）
4. 日语渐渐能说了。（过程）
5. 这么多作业，一天做不完。（きれない）
