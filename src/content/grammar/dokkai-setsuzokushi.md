## 一张表

| 功能 | 接续词 | 信号 |
|---|---|---|
| 顺接 | `だから` `したがって` `そのため` | 因果 |
| 逆接 | `しかし` `ところが` `にもかかわらず` | 转折，重点在后 |
| 添加 | `また` `さらに` `しかも` `その上` | 追加 |
| 对比 | `一方` `逆に` `反面` | 对比 |
| 总结 | `つまり` `要するに` `このように` | 结论 |
| 举例 | `たとえば` `具体的には` | 例证 |
| 换言 | `すなわち` `言い換えれば` | 定义 |
| 顺序 | `まず` `次に` `最後に` | 步骤 |

## 逆接：后面才是重点

```ja
しかし、問題(もんだい)は まだ 残(のこ)っています。
shikashi, mondai wa mada nokotte imasu
但是，问题仍然存在。

ところが、実際(じっさい)に 行(い)ってみると、違(ちが)いました。
tokoroga, jissai ni itte miru to, chigaimashita
然而，实际去了之后发现不一样。
```

## 总结：后面是作者结论

```ja
つまり、準備(じゅんび)が 足(た)りない ということです。
tsumari, junbi ga tarinai to iu koto desu
也就是说，准备不足。

要(よう)するに、方法(ほうほう)が 間違(まちが)っていたのです。
yousuru ni, houhou ga machigatte ita no desu
总之，方法错了。
```

## 举例：后面是例子，不是论点

```ja
たとえば、日本(にほん)の 例(れい)を 見(み)てみましょう。
tatoeba, nihon no rei o mite mimashou
例如，看看日本的例子。
```

## 读解技巧

- `しかし`、`ところが` 后面是作者真正想说的。
- `つまり`、`要するに` 是对前文的总结。
- `たとえば` 后面是例子，不是论点。
- `一方`、`反面` 提示对比。
- `だから`、`したがって` 提示因果。
- 接续词不是装饰，是文章的路标。

## 中国人容易错的地方

- **しかし 和 ところが 不同。** しかし 是转折，ところが 是"出乎意料"。
- **つまり 和 すなわち 不同。** つまり 是口语总结，すなわち 是定义。
- **だから 和 したがって 不同。** 后者更正式、更逻辑。
- **别跳过接续词。** 它们决定句子之间的关系。
- **读解先看问题，再找信号词。**

## 练一练
