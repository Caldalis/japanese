## 接法

名词或动词ます形去ます ＋ 気味（ぎみ）。当名词用：気味です、気味の N、気味で。

```ja
最近(さいきん) 少(すこ)し 太(ふと)り**気味(ぎみ)**です。
saikin sukoshi futori gimi desu
最近有点发胖。

風邪(かぜ)**気味(ぎみ)**なので、今日(きょう)は 早(はや)く 帰(かえ)ります。
kaze gimi na node, kyou wa hayaku kaerimasu
有点感冒，今天早点回去。

疲(つか)れ**気味(ぎみ)**の ときは 無理(むり)を しないでください。
tsukare gimi no toki wa muri o shinaide kudasai
觉得有点累的时候别硬撑。

工事(こうじ)は 予定(よてい)より 遅(おく)れ**気味(ぎみ)**です。
kouji wa yotei yori okure gimi desu
工程比计划稍微拖了一点。

試験(しけん)の 前(まえ)で、みんな 緊張(きんちょう)**気味(ぎみ)**でした。
shiken no mae de, minna kinchou gimi deshita
考试前，大家都有点紧张。

最近(さいきん) 運動(うんどう)不足(ぶそく)**気味(ぎみ)**です。
saikin undou busoku gimi desu
最近有点缺乏运动。
```

## 常用搭配

| 搭配 | 意思 |
|---|---|
| `風邪(かぜ)気味` | 有点感冒 |
| `疲(つか)れ気味` | 有点累 |
| `太(ふと)り気味` | 有点发胖 |
| `痩(や)せ気味` | 有点瘦了 |
| `遅(おく)れ気味` | 有点拖后 |
| `緊張(きんちょう)気味` | 有点紧张 |
| `焦(あせ)り気味` | 有点着急 |
| `不足(ぶそく)気味` | 有点不够 |
| `下(さ)がり気味` | 有下降的趋势 |

## 和 がち、っぽい 的区别

| | 说的是 | 例 |
|---|---|---|
| `〜気味` | 现在的状态，稍微偏了一点 | `風邪気味` 这会儿有点感冒 |
| `〜がち` | 频率，经常这样 | `風邪を ひきがち` 老爱感冒 |
| `〜っぽい` | 性质、倾向 | `熱っぽい` 感觉发热 |

`太り気味` 是"最近胖了一点"，`太りがち` 是"容易发胖"，不是一回事。

## 中国人容易错的地方

- **读 ぎみ，不是 きみ。** 单独的 `気味(きみ)が 悪い` 是"瘆人"，不同的词。
- **多用于坏事。** `元気気味`、`合格気味` 不说。
- **程度轻。** 真病倒了不说 風邪気味，说 `風邪を ひいた`。
- **动词接 ます形去ます。** `太る気味` 错。
- **它是名词，接 です、の。** `気味い`、`気味な` 都错。

## 练一练

1. 最近有点累。
2. 有点感冒，所以请假了。（休む）
3. 最近有点睡眠不足。（寝不足）
4. 销售额有点下滑。（売上、下がる）
