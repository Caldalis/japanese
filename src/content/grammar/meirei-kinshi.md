## 命令形

| 动词 | 命令形 |
|---|---|
| 五段 | え段：行(い)け、書(か)け、飲(の)め |
| 一段 | ろ：食(た)べろ、見(み)ろ |
| する | しろ |
| 来(く)る | 来(こ)い |

```ja
早(はや)く 来(こ)い。
hayaku koi
快点来。

黙(だま)れ。
damare
闭嘴。

早(はや)く 食(た)べろ。
hayaku tabero
快吃。
```

## 禁止形：辞书形 ＋ な

```ja
触(さわ)る**な**。
sawaru na
别碰。

ここに 入(はい)る**な**。
koko ni hairu na
别进来。

心配(しんぱい)する**な**。
shinpai suru na
别担心。
```

## なさい：长辈指示

Vます去ます ＋ なさい。对小孩、学生、下级。

```ja
早(はや)く 寝(ね)**なさい**。
hayaku ne nasai
早点睡。

宿題(しゅくだい)を し**なさい**。
shukudai o shi nasai
去写作业。
```

## てごらん：哄孩子、轻松建议

Vて ＋ ごらん。比 なさい 柔和，多对小孩或亲近的人。

```ja
ちょっと 見(み)**てごらん**。
chotto mite goran
你看一看。

食(た)べ**てごらん**。
tabete goran
你尝尝看。
```

## 语气从粗到柔

`行け` ＜ `行くな`（禁止）＜ `行きなさい` ＜ `行ってごらん` ＜ `行ってください`

## 中国人容易错的地方

- **命令形不是辞书形。** 行く 是辞书形，命令是 行け。
- **禁止形是辞书形＋な。** 行くな，不是 行きな。
- **なさい 接ます形去ます。** 寝なさい。
- **てごらん 接て形。** 見てごらん。
- **命令形和禁止形很粗。** 对上级绝不能用。
