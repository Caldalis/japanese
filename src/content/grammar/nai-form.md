## ない形能做什么

| 句型 | 意思 | 学在 |
|---|---|---|
| `〜ないでください` | 请别做 | 8.2 |
| `〜なければなりません` | 必须做 | 8.3 |
| `〜なくてもいいです` | 不做也行 | 8.4 |
| `〜ないで` | 不做某事而…… | 8.5 |
| `〜ない` | 简体的否定"不做" | 第 10 单元 |

## 二类和三类

| 类 | 规则 | 例 |
|---|---|---|
| 二类（一段） | 去 る 加 ない | `食(た)べる` → `食べない`，`見(み)る` → `見ない`，`起(お)きる` → `起きない` |
| 三类 | 固定 | `する` → `しない`，`来(く)る` → `来(こ)ない` |

来る 的ない形读 こない，不是 くない，这是三类动词里唯一要注意读音的地方。

## 一类：う段改成あ段

词典形最后一个假名从 う段 改成同一行的 あ段，再加 ない。

| 词尾 | 变成 | 例 |
|---|---|---|
| く | かない | `書(か)く` → `書かない`，`行(い)く` → `行かない` |
| ぐ | がない | `泳(およ)ぐ` → `泳がない` |
| す | さない | `話(はな)す` → `話さない` |
| つ | たない | `待(ま)つ` → `待たない` |
| ぬ | なない | `死(し)ぬ` → `死なない` |
| ぶ | ばない | `遊(あそ)ぶ` → `遊ばない` |
| む | まない | `飲(の)む` → `飲まない` |
| る | らない | `帰(かえ)る` → `帰らない`，`乗(の)る` → `乗らない` |
| う | **わない** | `買(か)う` → `買わない`，`会(あ)う` → `会わない` |

唯一的坑在最后一行：う 结尾不是变 あない，而是 わない。買わない、会わない、使わない、言わない。

特例：`ある` 的ない形是 `ない`，不是 あらない。

## 从 ます形出发

一类：ます 前面的い段假名改成あ段，加 ない。飲みます → 飲まない，買います → 買わない。二类：去 ます 加 ない。食べます → 食べない。

## 中国人容易错的地方

- **買う 变 買わない。** 不是 買あない。所有 う 结尾的一类动词都是 わ。
- **ある 的否定是 ない。** 本がない，不说 本があらない。
- **来ない 读 こない。** 来る 一家三口读音各不同：くる、きます、こない。
- **一类的 る 和二类的 る。** 帰る 一类 → 帰らない；見る 二类 → 見ない。和て形一样，查词性。
