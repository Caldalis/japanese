## 规则

た形加 `ことが あります`。否定 `ことが ありません`，从来没有加 `一度(いちど)も`。

```ja
日本(にほん)へ 行(い)っ**たことがあります**。
nihon e itta koto ga arimasu
去过日本。

寿司(すし)を 食(た)べ**たことがあります**か。
sushi o tabeta koto ga arimasu ka
吃过寿司吗？

富士山(ふじさん)に 登(のぼ)っ**たことがありません**。
fujisan ni nobotta koto ga arimasen
没爬过富士山。

飛行機(ひこうき)に 一度(いちど)も 乗(の)っ**たことがありません**。
hikouki ni ichido mo notta koto ga arimasen
一次也没坐过飞机。
```

## 怎么回答

| 问 | 答 |
|---|---|
| `〜たことがありますか` | `はい、あります` / `いいえ、ありません` |
| | `はい、一度(いちど) あります` 有过一次 |
| | `はい、何回(なんかい)も あります` 有过好几次 |
| | `いいえ、一度(いちど)も ありません` 一次也没有 |

## 和 ました 的区别

| | 说的是 | 例 |
|---|---|---|
| `〜ました` | 过去发生的某件事 | `去年 日本へ 行きました` 去年去了日本 |
| `〜たことがあります` | 有过这种经历 | `日本へ 行ったことがあります` 去过日本 |

被问"去过日本吗"要答 あります，答 行きました 像在说"去了"，对方会追问什么时候。

## 中国人容易错的地方

- **最近的事不用它。** 昨日 寿司を食べたことがあります 是错的，昨天的事就说 食べました。经验要有一点距离。
- **前面是た形。** 行きましたことが 是错的。
- **一度も 必须配否定。** 一度も あります 不成立。
- **中文的"过"不全是它。** "吃过饭了吗"是问有没有吃，日语是 ご飯を 食べましたか。只有"人生经历"的"过"才用 たことがあります。

## 练一练

1. 你去过京都吗？
2. 我看过日本的电影。
3. 我一次也没吃过纳豆。（纳豆 = 納豆 なっとう）

<details><summary>答案</summary>

1. 京都へ 行ったことがありますか。
2. 日本の 映画を 見たことがあります。
3. 納豆を 一度も 食べたことがありません。

</details>
