## 居然：句子 ＋ なんて

前面是一件出乎意料的事，后面说感想。感想可好可坏。

```ja
彼(かれ)が 嘘(うそ)を つく**なんて**、信(しん)じられません。
kare ga uso o tsuku nante, shinjiraremasen
他居然撒谎，真不敢相信。

こんな ところで 会(あ)える**なんて**、嬉(うれ)しいです。
konna tokoro de aeru nante, ureshii desu
居然能在这种地方见到你，真高兴。

一日(いちにち)で 全部(ぜんぶ) 覚(おぼ)えた**なんて**、すごいですね。
ichinichi de zenbu oboeta nante, sugoi desu ne
一天就全记住了，真厉害。

約束(やくそく)を 忘(わす)れる**なんて**、ひどいです。
yakusoku o wasureru nante, hidoi desu
居然忘了约定，太过分了。

まさか 合格(ごうかく)する**なんて** 思(おも)いませんでした。
masaka goukaku suru nante omoimasen deshita
没想到居然能考上。
```

后面的感想可以省：`彼が 嘘を つくなんて……`，意思自己体会。

## 什么的：名词 ＋ なんて / なんか

把那个东西看轻，后面多是否定或嫌弃。なんて 和 なんか 都行，なんか 更口语。

```ja
勉強(べんきょう)**なんて** 大嫌(だいきら)いです。
benkyou nante daikirai desu
学习什么的最讨厌了。

お金(かね)**なんか** いりません。
okane nanka irimasen
钱什么的不需要。

テレビ**なんか** 見(み)ている 時間(じかん)は ありません。
terebi nanka mite iru jikan wa arimasen
没时间看什么电视。

こんな 問題(もんだい)**なんて** 簡単(かんたん)です。
konna mondai nante kantan desu
这种题小菜一碟。
```

## 私なんか：自谦

说自己时是谦虚，日本人很常用。

```ja
私(わたし)**なんか** まだまだです。
watashi nanka madamada desu
我还差得远呢。

私(わたし)**なんて** 先生(せんせい)に 比(くら)べたら 全然(ぜんぜん) だめです。
watashi nante sensei ni kurabetara zenzen dame desu
我跟老师比差远了。
```

## なんて 和 なんか

| | 接什么 | 场合 |
|---|---|---|
| `なんて` | 名词、句子 | 口语和一般书面 |
| `なんか` | 只接名词 | 口语 |

`嘘を つくなんか` 错，句子后面只能 なんて。

助词：なんて、なんか 代替 は、が、を；に、で、と 保留，`東京になんか 行きたくない`。

## 顺便：なんか 的另一个用法

口语里 なんか 单独放句首是"总觉得、有点"：`なんか 変だ` 总觉得怪怪的，`なんか 眠い` 有点困。和本条无关，听得懂就行。

## 中国人容易错的地方

- **别人的东西别用。** 当着对方说 `あなたの 料理なんて` 是侮辱。
- **自谦可以。** `私なんか` 是客气，和中文"我这种人"一样。
- **句子后面只能 なんて。** なんか 只接名词。
- **"居然"的 なんて 后面要有感想。** 没有感想时用 とは 也行，更书面：`合格するとは 思わなかった`。
- **なんて 不是疑问词。** 和 何(なん)て 读音一样，`何て 言いましたか`（说了什么）是另一个词。
