## 简体会话的五个特征

**句尾去掉 です ます**，前两条学过了。

**问句靠语调**，句尾上扬，不加 か。名词和な形容词的 だ 去掉。

```ja
明日(あした)、来(く)る？
ashita, kuru
明天来吗？

これ、おいしい？
kore, oishii
这个好吃吗？

今(いま)、暇(ひま)？
ima, hima
现在有空吗？
```

**助词 は を へ 经常省掉**，に で と 一般保留。

```ja
ご飯(はん)、食(た)べた？
gohan, tabeta
吃饭了吗？

駅(えき)、行(い)く？
eki, iku
去车站吗？
```

**回答用 うん ううん**，不用 はい いいえ。

**句尾加 ね よ の**。の 放在问句末尾是关心的询问，放在陈述句末尾是解释。

```ja
どこ 行(い)く**の**？
doko iku no
去哪儿啊？

ちょっと 疲(つか)れた**の**。
chotto tsukareta no
有点累了。
```

## 缩略

| 完整 | 缩略 | 例 |
|---|---|---|
| `〜ている` | `〜てる` | 食べてる 在吃 |
| `〜てしまう` | `〜ちゃう` | 忘れちゃった 忘了 |
| `〜なければ` | `〜なきゃ` | 行かなきゃ 得走了 |
| `〜てはいけない` | `〜ちゃいけない` | 食べちゃいけない 不能吃 |
| `〜ておく` | `〜とく` | 買っとく 先买好 |
| `〜のだ` | `〜んだ` | 行くんだ 是要去 |

## 一段对话

```ja
昨日(きのう)、どこ 行(い)った**の**？
kinou, doko itta no
昨天去哪儿了？

新宿(しんじゅく)。映画(えいが) 見(み)**てきた**。
shinjuku. eiga mitekita
新宿。去看了场电影。

面白(おもしろ)**かった**？
omoshirokatta
好看吗？

うん、すごく よ**かった**。
un, sugoku yokatta
嗯，特别好。
```

换成敬体是：昨日 どこへ 行きましたか。新宿です。映画を 見てきました。面白かったですか。はい、とても よかったです。

## 对谁用

| 用简体 | 用敬体 |
|---|---|
| 朋友、同学、家人 | 老师、上司、长辈 |
| 比自己小的人 | 店员、陌生人、初次见面 |
| 自言自语、日记、朋友间的消息 | 邮件、报告、发言 |

拿不准就用敬体，用错敬体只是显得生分，用错简体会失礼。

## 中国人容易错的地方

- **对店员、路人不要用简体。** 问路 駅 どこ？ 很失礼，要 駅は どこですか。
- **简体问句不加 か。** 行くか 是粗鲁的男性说法。
- **听到 てる ちゃった なきゃ 要还原。** 它们是 ている てしまった なければ，不是新词。
- **の 的用法男女有别。** 陈述句末尾的 の 多是女性和孩子用，男性用 んだ。

## 练一练

改成朋友之间的简体说法。

1. 明日 学校へ 行きますか。
2. 宿題を 忘れてしまいました。
3. はい、もう 食べました。
