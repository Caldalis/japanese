## 对应关系

| 普通 | 丁宁 | 最丁宁 |
|---|---|---|
| `学生だ` | `学生です` | `学生でございます` |
| `本がある` | `本があります` | `本がございます` |
| `本がない` | `本がありません` | `本がございません` |
| `学生じゃない` | `学生ではありません` | `学生ではございません` |

## でございます：是

```ja
こちらが 会議室(かいぎしつ)**でございます**。
kochira ga kaigishitsu de gozaimasu
这里是会议室。

お電話(でんわ) ありがとうございます。ABC商事(しょうじ)**でございます**。
odenwa arigatou gozaimasu. eebiishii shouji de gozaimasu
感谢来电。这里是 ABC 商事。

お会計(かいけい)は 三千円(さんぜんえん)**でございます**。
okaikei wa sanzen en de gozaimasu
一共三千日元。

次(つぎ)は 新宿(しんじゅく)**でございます**。
tsugi wa shinjuku de gozaimasu
下一站新宿。
```

## ございます：有、在

```ja
お手洗(てあら)いは 一階(いっかい)に **ございます**。
otearai wa ikkai ni gozaimasu
洗手间在一楼。

他(ほか)の 色(いろ)も **ございます**。
hoka no iro mo gozaimasu
还有其他颜色。

申(もう)し訳(わけ)ございません。ただいま 在庫(ざいこ)が **ございません**。
moushiwake gozaimasen. tadaima zaiko ga gozaimasen
非常抱歉，现在没有库存。
```

## 固定说法里的 ございます

| 说法 | 来历 |
|---|---|
| `ありがとうございます` | ありがたい ＋ ございます |
| `おはようございます` | お早い ＋ ございます |
| `おめでとうございます` | めでたい ＋ ございます |
| `申(もう)し訳(わけ)ございません` | 申し訳ない 的最丁宁形 |
| `よろしゅうございます` | 古风，现在多说 よろしいです |

## 谁用

| 场合 | 用 |
|---|---|
| 商店、酒店、餐厅的服务人员 | 对客人说 でございます |
| 电话报公司名、自报姓名 | `〜でございます` |
| 广播、公告 | `〜でございます` |
| 普通公司对话 | です 就够 |
| 朋友、家人 | 绝不 |

## 中国人容易错的地方

- **ございます 不能说别人在。** 先生は 教室に ございますか 是错的，人用 いらっしゃいます。
- **ではございません 是否定。** でございません 也能听到，前者更标准。
- **不要全句敬语堆砌。** でございます 配 お〜になる 已经很正式，再加别的会显得滑稽。
- **听懂比会说重要。** 店员、广播、电话客服天天用它，自己说的机会不多。
