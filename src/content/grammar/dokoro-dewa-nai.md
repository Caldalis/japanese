## 接法

名词或动词辞书形 ＋ どころではない。口语说 どころじゃない。

```ja
試験(しけん)の 前(まえ)は、映画(えいが)を 見(み)る**どころではない**。
shiken no mae wa, eiga o miru dokoro dewa nai
考试前哪有工夫看电影。

風邪(かぜ)で、仕事(しごと)**どころではない**。
kaze de, shigoto dokoro dewa nai
感冒了，不是工作的时候。

忙(いそが)しくて、恋愛(れんあい)**どころではない**。
isogashikute, renai dokoro dewa nai
忙得哪有工夫谈恋爱。

お金(かね)が なくて、旅行(りょこう)**どころではない**。
okane ga nakute, ryokou dokoro dewa nai
没钱，哪谈得上旅行。
```

## 语感：有更紧迫的事

说话人不是"不想做 A"，而是"现在根本没条件做 A"。常带疲惫、无奈。

```ja
宿題(しゅくだい)が 終(お)わらなくて、ゲーム**どころじゃない**。
shukudai ga owaranakute, geemu dokoro janai
作业写不完，哪顾得上玩游戏。

今(いま)は それ**どころではない**。
ima wa sore dokoro dewa nai
现在不是管那个的时候。
```

## 和 どころか 的区别

| | 意思 | 例 |
|---|---|---|
| `どころか` | 与预想相反、别说 A 连 B | `安いどころか 高い` |
| `どころではない` | 没条件做 A | `遊ぶどころではない` |

`映画どころか、テレビも 見る 時間が ない` 是"别说电影，连电视都没时间"；`映画を 見る どころではない` 是"哪有工夫看电影"。

## 和 わけではない 的区别

`わけではない` 是"并不是……"：`嫌いな わけではない` 并不是讨厌。`どころではない` 是"不是做 A 的时候"。

## 中国人容易错的地方

- **前面接名词或辞书形。** 映画を見るどころではない。
- **不是"并不是"。** 那是 わけではない。
- **口语是 どころじゃない。** 更随意。
- **后项可以省略。** もう それどころではない。
- **语气带紧迫和无奈。**

## 练一练

1. 明天考试，哪有工夫打游戏。
2. 因为生病，不是工作的时候。
3. 现在不是谈那个的时候。
