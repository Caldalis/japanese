## 程度：从很到完全不

| 副词 | 意思 | 配什么 |
|---|---|---|
| `とても` | 很、非常 | 肯定 |
| `本当(ほんとう)に` | 真的 | 肯定 |
| `ちょっと` / `少(すこ)し` | 有点、稍微 | 肯定为主 |
| `あまり` | 不太 | **必须否定** |
| `全然(ぜんぜん)` | 完全不 | **必须否定** |

```ja
この 映画(えいが)は **とても** 面白(おもしろ)いです。
kono eiga wa totemo omoshiroi desu
这部电影很有意思。

今日(きょう)は **ちょっと** 寒(さむ)いです。
kyou wa chotto samui desu
今天有点冷。

この 本(ほん)は **あまり** 面白(おもしろ)**くない**です。
kono hon wa amari omoshirokunai desu
这本书不太有意思。

漢字(かんじ)が **全然** わかり**ません**。
kanji ga zenzen wakarimasen
汉字完全不懂。
```

## 频率：从总是到从不

| 副词 | 意思 | 配什么 |
|---|---|---|
| `いつも` | 总是 | 肯定 |
| `よく` | 经常 | 肯定 |
| `時々(ときどき)` | 有时 | 肯定 |
| `たまに` | 偶尔 | 肯定 |
| `あまり` | 不常 | **必须否定** |
| `全然(ぜんぜん)` | 从不 | **必须否定** |

```ja
私(わたし)は **いつも** 七時(しちじ)に 起(お)きます。
watashi wa itsumo shichiji ni okimasu
我总是七点起床。

**よく** 図書館(としょかん)で 勉強(べんきょう)します。
yoku toshokan de benkyou shimasu
经常在图书馆学习。

**時々** 映画(えいが)を 見(み)ます。
tokidoki eiga o mimasu
有时看电影。

お酒(さけ)は **あまり** 飲(の)み**ません**。
osake wa amari nomimasen
不常喝酒。

テレビは **全然** 見(み)**ません**。
terebi wa zenzen mimasen
完全不看电视。
```

## 数量：多和少

`たくさん` 很多，`少し` 一点，`大勢(おおぜい)` 很多人，只能用于人。放在动词前面，不加助词。

```ja
昨日(きのう) **たくさん** 食(た)べました。
kinou takusan tabemashita
昨天吃了很多。

公園(こうえん)に 人(ひと)が **大勢** います。
kouen ni hito ga oozei imasu
公园里有很多人。
```

## 位置

副词放在被修饰的谓语前面，通常紧挨着。话题 は 在前，副词在后：`私は いつも 〜`。

## 中国人容易错的地方

- **あまり、全然 后面忘了否定。** あまり おいしいです 是错的。中文"不太好吃"的"不"在日语里长在句尾。
- **とても 不配否定。** "很不好吃"不说 とても おいしくない，说 全然 おいしくない 或 あまり おいしくない。
- **よく 有两个意思。** 经常，也表示"好好地"：よく わかりました 明白了。看上下文。
- **ちょっと 还是委婉拒绝。** 被邀请时说 ちょっと……，意思是"有点不方便"，是拒绝。

## 练一练

1. 这家店的拉面很好吃。（拉面 = ラーメン）
2. 我不太看电视。
3. 我有时坐公交去公司。

<details><summary>答案</summary>

1. この 店の ラーメンは とても おいしいです。
2. 私は あまり テレビを 見ません。
3. 時々 バスで 会社へ 行きます。
