## 先学通用的：〜つ

一到十可以用日本固有的数法，不管数什么都行，十以上直接用数字。

| | | | | |
|---|---|---|---|---|
| `一つ(ひとつ)` | `二つ(ふたつ)` | `三つ(みっつ)` | `四つ(よっつ)` | `五つ(いつつ)` |
| `六つ(むっつ)` | `七つ(ななつ)` | `八つ(やっつ)` | `九つ(ここのつ)` | `十(とお)` |

问几个是 `いくつ`。这套和日期的 ふつか、みっか 是同一套词根，一起记省力。

## 常用量词

| 量词 | 数什么 | 特殊读法 |
|---|---|---|
| `〜人(にん)` | 人 | `一人(ひとり)` `二人(ふたり)` `四人(よにん)`；问 `何人(なんにん)` |
| `〜枚(まい)` | 纸、票、盘子、衬衫等扁平物 | 无；问 `何枚(なんまい)` |
| `〜本(ほん)` | 笔、瓶子、伞、电车线路等细长物 | `一本(いっぽん)` `三本(さんぼん)` `六本(ろっぽん)` `八本(はっぽん)` `十本(じゅっぽん)`；问 `何本(なんぼん)` |
| `〜冊(さつ)` | 书、本子 | `一冊(いっさつ)` `八冊(はっさつ)` `十冊(じゅっさつ)` |
| `〜匹(ひき)` | 猫狗鱼等小动物 | `一匹(いっぴき)` `三匹(さんびき)` `六匹(ろっぴき)` `八匹(はっぴき)` `十匹(じゅっぴき)`；问 `何匹(なんびき)` |
| `〜台(だい)` | 车、电脑、电视等机器 | 无 |
| `〜回(かい)` | 次数 | `一回(いっかい)` `六回(ろっかい)` `八回(はっかい)` `十回(じゅっかい)` |
| `〜階(かい)` | 楼层 | `一階(いっかい)` `三階(さんがい)` `六階(ろっかい)`；问 `何階(なんがい)` |
| `〜歳(さい)` | 年龄 | `一歳(いっさい)` `八歳(はっさい)` `十歳(じゅっさい)` `二十歳(はたち)`；问 `何歳(なんさい)` 或 `おいくつ` |
| `〜杯(はい)` | 杯、碗 | `一杯(いっぱい)` `三杯(さんばい)` `六杯(ろっぱい)` `八杯(はっぱい)` `十杯(じゅっぱい)` |
| `〜個(こ)` | 小的立体物 | `一個(いっこ)` `六個(ろっこ)` `八個(はっこ)` `十個(じゅっこ)` |

音变只有一套规律：量词以 か さ た は 行开头时，一 六 八 十 后面促音，は 行还变 ぱ；三 后面 は 行变 ば。记住 本 的一列，匹 杯 完全一样。

## 位置：放在动词前面

数量词紧挨着动词，不放在名词和助词之间。

```ja
りんごを 三(みっ)つ 買(か)いました。
ringo o mittsu kaimashita
买了三个苹果。

教室(きょうしつ)に 学生(がくせい)が 二十人(にじゅうにん) います。
kyoushitsu ni gakusei ga nijuu nin imasu
教室里有二十个学生。

切手(きって)を 五枚(ごまい) ください。
kitte o gomai kudasai
请给我五张邮票。

ビールを 二本(にほん) お願(ねが)いします。
biiru o nihon onegai shimasu
请来两瓶啤酒。

猫(ねこ)を 一匹(いっぴき) 飼(か)っています。
neko o ippiki katte imasu
养了一只猫。

週(しゅう)に 三回(さんかい) ジムへ 行(い)きます。
shuu ni sankai jimu e ikimasu
一周去三次健身房。

弟(おとうと)は 十八歳(じゅうはっさい)です。
otouto wa juuhassai desu
弟弟十八岁。

本屋(ほんや)は 三階(さんがい)に あります。
honya wa sangai ni arimasu
书店在三楼。
```

## 中国人容易错的地方

- **本 不是书。** 日语的 本 数细长的东西：ペン一本、ビール二本、傘三本。书用 `冊(さつ)`。
- **位置不同。** 中文"三个苹果"量词在名词前，日语 りんごを 三つ 在助词后面。想说"三个苹果"作主语，也是 りんごが 三つ あります。
- **一人 二人 不是 いちにん、ににん。** 这两个是固有读法。三人以上才规则。
- **二十歳 读 はたち。** 这是成年年龄，有专门的词。
- **三階 读 さんがい。** 楼层的 三 后面浊化，次数的 三回 不变。

## 练一练

1. 请给我两张票。（票 = 切符 きっぷ）
2. 家里有三只狗。
3. 一个月看两次电影。（一个月 = 月に）
