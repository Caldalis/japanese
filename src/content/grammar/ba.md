## 变形规则

| 词类 | 规则 | 例 |
|---|---|---|
| 一类动词 | 词尾 う段 改 え段，加 ば | `行(い)く` → `行けば`，`買(か)う` → `買えば`，`話(はな)す` → `話せば` |
| 二类动词 | 去 る 加 れば | `食(た)べる` → `食べれば`，`見(み)る` → `見れば` |
| 三类 | 固定 | `する` → `すれば`，`来(く)る` → `来(く)れば` |
| 动词否定 | ない → なければ | `行かない` → `行かなければ` |
| い形容词 | い → ければ | `安(やす)い` → `安ければ`，`いい` → `よければ` |
| い形容词否定 | くない → くなければ | `高くなければ` |
| な形容词、名词 | ＋ なら(ば) | `静かなら` `学生なら` |

和可能形对照：行ける 是"能去"，行けば 是"去的话"，只差 る 和 ば。

## 用法

**一般条件和假设**

```ja
安(やす)**ければ**、買(か)います。
yasukereba, kaimasu
便宜的话就买。

時間(じかん)が あ**れば**、京都(きょうと)へ 行(い)きたいです。
jikan ga areba, kyouto e ikitai desu
有时间的话想去京都。

毎日(まいにち) 練習(れんしゅう)す**れば**、上手(じょうず)に なります。
mainichi renshuu sureba, jouzu ni narimasu
每天练的话会变好。

急(いそ)が**なければ**、間(ま)に合(あ)いません。
isoganakereba, maniaimasen
不快点就赶不上。
```

**问怎么办才好**

```ja
どう す**れば** いいですか。
dou sureba ii desu ka
该怎么办才好？

どこで 切符(きっぷ)を 買(か)**えば** いいですか。
doko de kippu o kaeba ii desu ka
在哪里买票好？
```

`〜ばいい` 也用来建议："做……就行"：薬を 飲めば いいですよ。

## 一个限制

前句是动作，后句是自己的意志、命令、邀请时，ば 不自然，改用 たら。前句是状态（形容词、ある、いる、可能形）则没有限制。

| | |
|---|---|
| 安ければ、買いましょう | 对，前句是状态 |
| 東京へ 行けば、連絡してください | 不自然，改 行ったら |

## 中国人容易错的地方

- **一类动词的 ば 不是 ければ。** 行けば 对，行ければ 是可能形加 ば，意思是"能去的话"。
- **い形容词是 ければ。** 安いば 是错的。
- **名词不是 だば。** 学生なら 或 学生であれば。
- **ば 不表示"一旦"。** 必然的因果用 と。

## 练一练

1. 天气好的话去散步。
2. 怎么去车站好？（用 ばいい）
3. 不学习的话会不及格。（不及格 = 落ちます）

<details><summary>答案</summary>

1. 天気が よければ、散歩に 行きます。
2. 駅へ どう 行けば いいですか。
3. 勉強しなければ、試験に 落ちます。

</details>
