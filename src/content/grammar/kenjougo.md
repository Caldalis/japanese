## 做法一：お〜します

ます形去 ます，前面加 お，后面加 します。汉语动词用 ご〜します。再谦虚一级用 `いたします`。

```ja
荷物(にもつ)を **お持(も)ちします**。
nimotsu o omochi shimasu
我来帮您拿行李。

駅(えき)まで **お送(おく)りします**。
eki made ookuri shimasu
我送您到车站。

後(のち)ほど **ご連絡(れんらく)します**。
nochihodo gorenraku shimasu
稍后与您联系。

会場(かいじょう)を **ご案内(あんない)いたします**。
kaijou o goannai itashimasu
我来为您带路。

明日(あした) また **お電話(でんわ)いたします**。
ashita mata odenwa itashimasu
明天再给您打电话。
```

这个做法只用于**涉及对方**的动作：帮对方拿、送对方、联系对方。自己一个人走路不能说 お歩きします。

## 做法二：特殊动词

| 普通 | 谦让语 | ます形 |
|---|---|---|
| `行く` `来る` | `参(まい)る` | `参ります` |
| `言う` | `申(もう)す` `申し上(あ)げる` | `申します` |
| `する` | `いたす` | `いたします` |
| `いる` | `おる` | `おります` |
| `食べる` `飲む` `もらう` | `いただく` | `いただきます` |
| `見る` | `拝見(はいけん)する` | `拝見します` |
| `聞く` `訪ねる` | `伺(うかが)う` | `伺います` |
| `あげる` | `差(さ)し上(あ)げる` | `差し上げます` |
| `知る` `思う` | `存(ぞん)じる` | `存じます` |
| `会う` | `お目(め)にかかる` | `お目にかかります` |

```ja
王(おう)と **申(もう)します**。
ou to moushimasu
我姓王。

明日(あした) 三時(さんじ)に **伺(うかが)います**。
ashita sanji ni ukagaimasu
明天三点拜访您。

資料(しりょう)を **拝見(はいけん)しました**。
shiryou o haiken shimashita
资料我看过了。

社長(しゃちょう)は ただいま 席(せき)を 外(はず)して **おります**。
shachou wa tadaima seki o hazushite orimasu
社长现在不在座位上。

お名前(なまえ)は **存(ぞん)じて おります**。
onamae wa zonjite orimasu
您的名字我知道。
```

## 两种谦让

| 类 | 性质 | 例 |
|---|---|---|
| 谦让语Ⅰ | 动作有对象，对对象表敬意 | `伺う` `差し上げる` `お送りする` |
| 谦让语Ⅱ | 只是对听话人谦虚，动作可以没有对象 | `参る` `申す` `おる` `いたす` |

所以 参ります 可以用在"我明天去大阪"（大阪不是人），伺います 则必须是去拜访某人。

## 自己人也要压低

对外人说自己的上司、家人、公司，一律谦让语，不加 さん。

```ja
田中(たなか)は ただいま 外出(がいしゅつ)して **おります**。
tanaka wa tadaima gaishutsu shite orimasu
田中现在外出了。（对客户说自己同事）

父(ちち)が よろしくと **申(もう)して おりました**。
chichi ga yoroshiku to moushite orimashita
我父亲让我向您问好。
```

## 中国人容易错的地方

- **谦让语只能说自己和自己人。** 先生が 参ります 是错的，先生是对方。
- **お〜します 要有对方。** 私は お帰りします 是错的，回家不涉及对方。
- **对外说自己上司不加 さん，不用尊敬语。** 这是中国人最难接受的一点，但在日本公司里是铁律。
- **いただきます 三个意思。** 吃、喝、收到，都是压低自己。
