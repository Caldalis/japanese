# 日语笔记

给中文母语者的日语学习站。从五十音的汉字字源开始：平假名是汉字草书，片假名是汉字偏旁，你已经认识全部原材料。

在线地址：https://caldalis.github.io/japanese/

## 现在有什么

- **五十音**：46 个清音的字源、读音、记法；浊音、拗音、长音、促音；14 组易混字对比；随机测验和错题重练。清音表可以隐藏罗马音、乱序显示，用来自测。
- **读音**：所有假名、例词、例句和笔记里的词块都有预先生成的 mp3，任何手机浏览器都能放，不依赖系统语音。
- **词汇**：按主题分组的 N5 词表，每个词带读音、词性、例句、提示和音频。闪卡加间隔复习，有只听不看的听力模式，进度存在本机。
- **语法**：N5 到 N2 共 40 个单元的完整路线，N5 的 12 个单元 67 条已写完，N4 已写第 13 到 18 单元。每条有规则表、可朗读的例句（带振假名）、中国人易错点和练习。
- **笔记**：假名的来历、怎么练才快。
- 手机优先，支持深色模式，可加到主屏幕。

## 本地开发

需要 Node 22 以上和 pnpm。

```bash
pnpm install
pnpm dev        # http://localhost:4321/japanese/
pnpm build      # 输出到 dist/
pnpm check      # 类型检查
```

```bash
pnpm audio          # 为新增的日语文本生成 mp3 到 public/audio/，只生成缺的
pnpm audio --check  # 只看缺几个
pnpm audio --prune  # 顺便删掉没人用的音频
```

推到 `main` 分支后，GitHub Actions 自动构建并发布到 GitHub Pages。发布前会自动补生成缺少的音频，所以直接在 GitHub 网页上改 Markdown 也能上线带读音的内容，本地跑一次 `pnpm audio` 并提交则更稳。

### 读音是怎么来的

音频由微软 Edge 的神经网络日语语音（ja-JP-NanamiNeural）生成，语速放慢 10%。文件名是文本的哈希，浏览器按同一规则找文件，找不到时退回系统语音。`public/audio/index.json` 列出了每个文件对应的文本。

单个假名的音频不是单独合成的。语音引擎单独读一个假名时会用感叹的语调，音高偏高、拖长、尾音上扬，だ行最明显。所以脚本把每一行整行合成一次（例如 ダ、ヂ、ヅ、デ、ド），用引擎返回的字边界时间戳把每个字切出来，单字和整行听到的完全一致。这一步需要 ffmpeg，没有的话退回逐字合成并打印警告。`pnpm audio --kana` 强制重新生成全部假名音频。

## 怎么改内容

| 想改什么 | 改哪里 |
|---|---|
| 假名、字源、记法、易混组、长音例词 | `src/data/kana.ts` |
| 加一组词 | 在 `src/data/vocab/` 新建 `.json`，见下面的写法 |
| 加一条语法 | 在 `src/content/grammar/` 新建 `.md`，见下面的写法 |
| 语法单元的名字和规划 | `src/data/grammar.ts` |
| 加一篇笔记 | 在 `src/content/notes/` 新建 `.md`，写好 frontmatter（title、description、order、updated、tags） |
| 站名、口号、仓库地址 | `src/site.ts` |
| 颜色、字体 | `src/styles/global.css` 顶部的 token |

### 加一组词

新建 `src/data/vocab/xxx.json`，文件名就是网址：

```json
{
  "title": "人与称呼",
  "desc": "一句话说明这组词",
  "level": "N5",
  "order": 2,
  "words": [
    ["友達", "ともだち", "n", "朋友", "友達(ともだち)と 映画(えいが)を 見(み)ます。|和朋友看电影。", "提示，可留空"]
  ]
}
```

每个词一行，六项依次是：词、读音、词性、中文、例句、提示。例句写成 `日语|中文`，日语里用 `汉字(かな)` 标注音；例句和提示可以留空字符串。提示里要用引号请用中文的“”。

词性代码：`n` 名词、`v5` 一类动词、`v1` 二类动词、`vs` する动词、`vk` 来る、`adj-i` い形容词、`adj-na` な形容词、`adv` 副词、`expr` 固定表达、`num` 数词、`pron` 代词、`conj` 连词、`other` 其他。

加完跑一次 `pnpm audio`，给新词和例句生成读音。

### 写一条语法

新建 `src/content/grammar/xxx.md`，文件名就是网址。开头的 frontmatter：

```yaml
---
title: を・に・へ・で：动作句的四个标签   # 页面标题
pattern: N を V / N に V                  # 句型，大字显示
description: 一句话说明这条讲什么
level: N5                                # N5 到 N1
stage: 2                                 # 属于第几单元，见 src/data/grammar.ts；写好后把这条从该单元的 planned 里删掉
order: 4                                 # 单元内的顺序
updated: 2026-10-27
tags: [助词を, 助词に]
---
```

正文是普通 Markdown，另外有三个约定：

1. **例句卡**：用 ```` ```ja ```` 代码块写，每个例句一组，组之间空一行。第一行日语，后面可以跟罗马字（纯英文字母）和中文翻译，顺序随意。构建时会变成带朗读按钮的卡片。
2. **振假名**：日语里写 `漢字(かな)`，比如 `学生(がくせい)`，显示成注音，朗读时按假名读。
3. **高亮语法点**：日语里用 `**〜**` 包住要强调的部分。

```` markdown
```ja
私(わたし)は 学生(がくせい)**です**。
watashi wa gakusei desu
我是学生。

田中(たなか)さんは 先生(せんせい)ですか。
田中先生是老师吗？
```
````

正文里的行内反引号 `` `は` `` 约定为日语词或语法点：含日语且没有拉丁字母的会变成可点读的词块，`` `行(い)きます` `` 这样写还会带注音；像 `` `N1 は N2 です` `` 这种有字母的句型骨架只高亮不朗读。练习答案放在 `<details><summary>答案</summary>` 里，前后各空一行。

内容有错或想补充，欢迎提 Issue 或 PR。
